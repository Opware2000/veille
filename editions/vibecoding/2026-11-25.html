Veille r/vibecoding — mercredi 25 novembre 2026

En bref

Le codage agentic s'équipe d'une multitude d'utilitaires pour surveiller, coordonner et auditersessessions (Second Brain, Wakeshift, Verfy, Harny, Show-Context). Z.ai publie GLM-5.4, premier « loop transformer », qui promet un raffinement itératif des sorties de code. Enfin, le navigateur Ladybird franchit le cap de l'alpha.

Applications et outils nouveaux

Songe — entraînement distribué de modèles locaux sur compute idle

Sous Labs a publié Songe, un moteur d'entraînement qui capitalise sur les cycles CPU/GPU inutilisés d'un parc de machines pour réentraîner son propre modèle local. L'approche repose sur un framework distribué minimaliste : chaque nœud signale sa capacité disponible, et le coordinateur agrège les gradients. Licence Apache 2.0, environ 650 étoiles, dernière activité hier. Idéalement adapté aux chercheurs ou petites équipes disposant de machines hibernant souvent (postes de bureau, serveurs de développement).

FireVoice — studio vocal libre exécuté localement sur GPU

Fabwaseem présente FireVoice, un studio vocal desktop (Windows/Linux) gratuit tournant entièrement sur GPU local. Il couvre TTS, clonage de voix, dictée, doublage et transcription. Aucun contenu n'est envoyé à un service cloud. Développé en Python, ce projet s'inscrit dans la mouvance des outils vocaux open source (au même titre que Piper ou Kokoro). Lien direct vers le site de démonstration et les instructions d'installation.

Localcode — codage agentic open source en une commande sur Mac

MJWSolo annonce Localcode, un environnement de codage agenticopen source destiné à macOS. Une seule commande installe tout le nécessaire : agent capable d'intervenir dans le projet courant avec des outils standard (shell, éditeur, navigateurfichiers). Le projet, sous licence Apache 2.0 (~180 étoiles), se positionne comme une alternative locale aux solutions SaaS propriétaires comme Devin ou Cursor One.

Rune — VM Rust pour Emacs

Rune est une machine virtuelle écrite en Rust pour exécuter du code Emacs-Lisp. Elle vise à résoudre plusieurs problèmes classiques d'Emacs : démarrage lent, gestion de la concurrence et portabilité binaire. Avec 844 étoiles et une licence GPL-3.0, Rune n'est pas encore prête pour un usage quotidien mais mérite une surveillance si vous développez des extensions Emacs complexes. Dernière mise à jour en octobre.

Stalwart 1.2 — serveur de messagerie libre en remplacement direct d'Exchange

Stalwart Labs annonce la version 1.2 de Stalwart, serveur de messagerie et collaboration écrit en Rust. Cette version introduit une compatibilité drop-in avec Microsoft Exchange : IMAP, POP3, SMTP, CalDAV, CardDAV, WebDAV et un protocole JMAP propriétaire. Licence AGPL-3.0. Pour Nicolas qui gère deux boîtes (hermes@ogier.me et nogier@ac-dijon.fr), Stalwart pourrait intéresser s'il souhaite migrer vers un stack mail totalement indépendant d'Orange/France Télécom.

Dez v0.60 — codage agentic sandboxé dans l'éditeur

Zed intègre désormais le codage agentic directement dans l'éditeur Dezen mode sandboxé. Les sessions peuvent lancer des commandes shell dans un contexte isolé. La version 0.60 ajoute également le support multi-fournisseurs LLM. Libre, zéro prix.

Tempo — évaluateur partiel pour C

L'équipe Phoenix du laboratoire Bordelais (LaBRI) publie Tempo, un évaluateur partiel pour le langage C. Plutôt qu'un outil grand public, il s'agit d'un programme compilateur spécialisé : il prend en entrée un programme C et certaines de ses valeurs d'entrée, et produit un programme optimisé où les expressions connues statiquement sont calculées à la compilation. Utile pour les développeurs C soucieux de performance.

Nospeaker — le trackpad du MacBook qui « parle »

Nospeaker utilise le moteur haptique du trackpad MacBook Pro (et Air M-series) pour produire des sons. L'idée : convertir des notifications, de la musique ou n'importe quel signal audio en vibrations tactiles. 1 750 étoiles MIT, dernière mise à jour hier. Accessoirement utile, fondamentalement fascinant.

Mason — réplica PostgreSQL read-only basé sur DuckDB

Mason Data présente Mason, un remplaçant drop-in pour les réplicas PostgreSQL en lecture seule. Il stocke les données en format columnar (via DuckDB) et offre une API compatible PostgreSQL. Idéal pour délester les requêtes analytiques de la base principale. Open source. Article « Show HN » avec ~72 points sur Hacker News.

Genesis Map — visualisation des changements d'agents IA

Genesis Agent Infra publie Genesis Map, un outil de visualisation des modifications apportées par un agent IA au cours d'une session de codage. Il montre quelles lignes ont été ajoutées, supprimées ou modifiées, avec indication des zones à risque. Répond au problème bien réel de la confiance : quand l'agent écrit du code plus vite que le humain ne peut le relire, il faut un moyen de comprendre rapidement l'étendue des changements.

Wakeshift — événements MCP interoperables pour les agents de codage

Wakeshift ouvre en open source un serveur d'événements MCP (Model Context Protocol Events) fonctionnant avec Claude Code, Codex, Cursor et d'autres harness. Il permet à n'importe quel serveur MCP d'émettre des événements push vers les agents abonnés, y compris ceux qui ne supportent pas nativement le spec MCP Events. 3 points HN, sujet de niche mais potentiellement crucial dès que plusieurs agents coopèrent.

Second Brain — mémoire partagée entre Claude, ChatGPT et Cursor via MCP

Bhushan lance Second Brain, une solution MCP qui offre une mémoire commune synchronisée entre Claude Code, ChatGPT (Codex) et Cursor. Chaque agent lit et écrit dans le même espace, évitant de perdre le contexte en changeant d'outil. 3 points HN.

Extensions et greffons

datasette-charts 0.2a0 + intégration Datasette Agent

Simon Willison publie la version 0.2a0 de datasette-charts, un greffon de visualisation pour Datasette. Contrairement à un simple graphique statique, il suggère des types de graphique en fonction des données et les génère automatiquement. La nouveauté de cette version : intégration directe avec Datasette Agent, permettant de demander un graphique à chat et d'en obtenir un généré en temps réel. Gratuit, open source. Essai possible sur agent.datasette.io.

Toolfence-scan — vérification statique des skills Cursor/Claude/Copilot

Stock Gorilla lance toolfence-scan, un outil de vérification statique pour les skills des assistants de codage (Cursor, Claude Code, Copilot). Il analyse les définitions de skills et signale les comportements risqués (appels réseau non autorisés, exécutions shell dangereuses, lectures de fichiers sensibles) avant qu'ils ne soient déployés. Gratuit, licence MIT. Petit mais pertinent pour quiconque déploie des skills personnalisés.
