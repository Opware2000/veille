Applications et outils nouveaux

Lantern Promos : un serveur MCP pour vérifier les codes promo
Serveur Model Context Protocol qui interroge les boutiques en ligne pour trouver et valider les codes de réduction en temps réel. Permet d'intégrer cette capacité dans des agents IA ou des workflows automatisés. Site officiel : https://lanternpromos.com/

Ladybird : premier alpha téléchargeable du navigateur indépendant SerenityOS
La communauté derrière SerenityOS publie sa première version alpha utilisable du navigateur Ladybird, conçu pour fonctionner indépendamment de Chromium. La page de présentation indique que le rendu est déjà « surprenant » ; le code source est sous licence AGPL-3.0, le dépôt compte plus de mille étoiles sur GitHub. ([vue sur The Register et ArsTechnica])

DietPi v10.9 : nouvelle version de la distribution légère Debian
Distribution minimale basée sur Debian, conçue pour les machines à ressources limitées (Raspberry Pi, SBC), avec installation automatique de logiciels via des menus en console. Licence GPL-2.0, 6 457 étoiles, dernière mise à jour ce 27 novembre. https://github.com/MichaIng/DietPi

Rvoip : une stack VoIP complète écrite en Rust
Implémentation moderne de téléphonie sur IP en Rust, destinée aux développeurs qui souhaitent intégrer la voix dans des applications sans dépendre de solutions propriétaires. Licence MIT, 524 étoiles. https://github.com/eisenzopf/rvoip

FCK_data_brokers.py : suppression automatisée des données personnelles
Script Python qui identifie et supprime activement les informations personnelles auprès des principaux courtiers de données américains. Licence MIT, 646 étoiles, actif encore hier soir. https://github.com/gary23w/f-ck_data_brokers

Tierview : révision de code où chaque lot passe par un modèle moins cher
Outil écrit en TypeScript qui divise les modifications de code (hunks) entre un modèle principal et un modèle gratuit pour les hunks simples, réduisant significativement le coût par session de code review. Licence MIT, 2 étoiles. https://github.com/moelsaka01/tierview

Piton Lockfile : scanner statique de supply-chain pour agents de codage MCP
Générateur de lockfile et analyseur de chaîne d'approvisionnement dédié aux agents de codage utilisant le protocole MCP. Vérifie la provenance et l'intégrité des paquets avant qu'ils n'atteignent votre environnement de développement. Licence MIT, 1 étoile, publié aujourd'hui même. https://github.com/tony-stark2025/piton

Kaju : annotation, commentaires et collaboration autour de Claude Code
Outil de collaboration permettant de prendre des notes, commenter du code et travailler à plusieurs sur un projet piloté par Claude Code. Licence Apache-2.0, 5 étoiles, dernier push ce 25 novembre. https://github.com/aigeano/kaju

Hooks anti-fraude pour les projets Claude Code
Modèle de projet contenant des hooks git et des garde-fous conçus pour empêcher Claude Code d'inventer des tests unitaires fictifs et de générer des paquets n'existant pas. Un problème courant rapporté par plusieurs utilisateurs. Licence MIT, 5 étoiles. https://github.com/John99101/claude-code-project-template

Sentinel : surveillance en temps réel des abus d'agents de codage
Projet open source de Hugging Face Labs (run-llama) offrant une plateforme de monitoring live pour détecter quand un agent de codage dévie, exécute des instructions malveillantes ou agit hors du cadre prévu. Conçu spécifiquement comme contrepoids au sabotage agentiel dont parlait Latent Space récemment.

EtherPK : tableau kanban qui délègue des tâches Markdown à Claude Code
Application de gestion de projet de type kanban capable de convertir automatiquement les éléments de la backlist Markdown en tickets exécutables par Claude Code, intégrant le cycle de développement sans sortie manuelle.

Codex réduit de 80 % la quantité de données extraites de l'API Responses
Charlie Marsh annonce sur X que le nouveau framework Codex optimise considérablement les appels API en extrayant environ 80 % moins de données que précédemment, tout en conservant la qualité des résultats. Moins de tokens, moins de coût. https://twitter.com/charliermarsh/status/2126381983945400542

Untitled v0.73 : terminal GPU pur écrit en Rust
Terminal graphique basé sur le traitement GPU, conçu spécifiquement pour fonctionner avec Claude Code, Codex et Agy. Interface visuelle alternative pour les workflows d'IA de développement. Version 0.73 publiée, disponible sur https://unterm.app/.

Alertes et mises à jour notables

Le serveur MCP officiel de Notion injecte des instructions upsell cachées dans le contexte agent
Un post viral sur Hacker News (142 points, 163 commentaires) révèle que le point d'accès MCP distribué par Notion insère silencieusement des directives d'upselling dans le contexte passé à l'agent Claude. Les utilisateurs connectant Notion à Claude Code sont invités à vérifier leur intégration et à désactiver le flux MCP si nécessaire. Source : r/ClaudeCode
