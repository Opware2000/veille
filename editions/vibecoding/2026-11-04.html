En bref

Trente-deux messages parus depuis la dernière édition, dont cinq annoncent un outil utilisable : trois projets libres dont le code est publié, et deux applications web gratuites mais propriétaires. Le plus intéressant est Kiiri, un petit chat de bureau qui surveille plusieurs agents de codage à la fois et expose un serveur MCP local ; viennent ensuite BreadPilot, qui apprend à câbler un microcontrôleur sur une maquette 3D en vérifiant le montage, et Polyspoon, bibliothèque d'objets 3D libres générés par recettes. Le reste est composé de questions, de récits de fabrication et de démonstrations sans logiciel à installer.

Applications et outils nouveaux

Kiiri — savoir lequel de ses agents attend une réponse

Petite application de bureau qui affiche un chat sur l'écran. Le chat s'agite tant qu'un agent travaille et sonne dès que l'un d'eux a fini ou réclame une intervention, chaque session gardant son propre état : on n'a plus à passer d'une fenêtre de VS Code à l'autre pour voir laquelle est bloquée. Elle gère Claude Code, Cursor, Codex et Antigravity. L'outil fonctionne aussi dans l'autre sens : il fait tourner un serveur MCP local, si bien qu'un agent peut le faire parler ou désigner un point de l'écran (« quand les tests finissent, montre-moi le premier échec »). Une fonction de lecture d'écran, déclenchée par Ctrl+Alt, a été ajoutée sur le modèle de Clicky.

Licence MIT, gratuit, macOS et Windows, fonctionne avec sa propre clé d'API ou entièrement en local via Ollama. Réserve signalée par l'auteur : les binaires ne sont pas encore signés, un avertissement du système d'exploitation est donc à prévoir. Site : https://kiiri.app — dépôt : https://github.com/kiiri-app/kiiri (2 étoiles, dernière mise à jour le 3 novembre 2026).

BreadPilot — apprendre à câbler une maquette d'électronique en trois dimensions

Application de bureau qui affiche une maquette (breadboard) en trois dimensions, navigable et zoomable, et explique pas à pas où enfoncer chaque fil et chaque composant sur le microcontrôleur. L'auteur, sans expérience en électronique, partait d'un problème concret : les modèles de langue répondent par des tableaux de correspondances broche/fil difficiles à suivre quand on débute. Le programme vérifie en outre que le câblage décrit ne provoque pas de court-circuit avant de le valider. Un agent intégré part de l'idée de l'utilisateur, choisit les composants, découpe le projet en étapes et écrit le code ; l'agent utilise Ollama par défaut (modèle local au choix) et accepte aussi une API OpenAI. L'auteur a bâti plus de vingt projets avec, surtout des montages simples (bouton, écran OLED, diodes), et indique ne pas avoir testé les montages complexes.

Licence Apache-2.0, gratuit. Dépôt : https://github.com/Prestical/BreadPilot (0 étoile, dépôt créé le 23 octobre 2026, dernière mise à jour le 3 novembre 2026).

ChessGrind — entraîneur d'échecs avec révision espacée

Application web d'entraînement aux échecs : on résout un exercice ou joue une partie, on enregistre la position qui a révélé une faiblesse, et un carnet de révision la fait revenir à intervalles croissants. Le contenu annoncé est de 1 000 positions originales, 200 exercices d'ouverture, des parties complètes et un répertoire. Point de méthode intéressant : l'auteur a délibérément gardé la logique du jeu hors du « vibecoding », la bibliothèque chess.js restant la référence pour les coups légaux, avec des positions et solutions validées à part — ce qui évite qu'une interface flatteuse invente les règles.

L'échiquier est gratuit et ne demande aucun compte externe. Incertitude : l'application n'est pas libre (aucun code publié) et une formule facultative « Founder » à 3,99 dollars ajoute la synchronisation privée entre appareils. Application : https://chessgrind.fyi

Polyspoon — bibliothèque d'objets 3D libres, construits par recettes

Version libre et communautaire de Polyfork. Chaque modèle est une recette, c'est-à-dire un petit programme à paramètres nommés : on ouvre un modèle, on change son type, sa taille, ses parties et ses couleurs, et il se reconstruit en direct dans le navigateur. Chaque page fournit le fichier GLB, la source de la recette et du code à copier pour three.js, Unity, Godot ou Blender. L'intérêt du projet tient à son moteur partagé : toutes les recettes reposent sur un générateur commun, si bien qu'une amélioration acceptée sur les toitures ou les colombages améliore d'un coup tous les modèles qui s'en servent. L'auteur a corrigé le reproche fait à sa première annonce — il fallait un compte pour seulement regarder le catalogue — la navigation et le téléchargement se font désormais sans inscription, et le code qui envoie le lien de connexion est public.

Licence Apache-2.0, gratuit. État annoncé honnêtement par l'auteur : 141 modèles, de qualité inégale, les rochers étant encore à retravailler. Site : https://polyspoon.com — dépôt : https://github.com/DITlieD/polyspoon (11 étoiles, dépôt créé le 26 octobre 2026, dernière mise à jour le 3 novembre 2026). Deux messages distincts ont annoncé le projet dans l'intervalle : l'annonce initiale et ce point d'étape détaillé.
