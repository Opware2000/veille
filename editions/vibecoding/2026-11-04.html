Applications et outils nouveaux

OpenMarkdown — écrire dans le même fichier que son agent

Éditeur Markdown local-first dont le cœur est écrit en Rust (ouverture en moins de 0,2 s annoncée), pensé pour que l'humain et l'agent travaillent dans le même document plutôt que dans une fenêtre de conversation à côté. Le terminal de l'agent s'ouvre dans la barre latérale et le modèle lit, cherche et écrit là où l'on regarde : on lui demande de rédiger sous un titre précis, seule cette section change ; on sélectionne un passage et le modèle le remanie sur place ; si l'on coche une case à la main, il reprend à partir de là. Aucune IA n'est embarquée : l'éditeur pilote l'agent déjà installé (Claude Code, Codex, Gemini CLI, Copilot, Cursor, opencode) par le protocole MCP, la question du coût et du fournisseur reste donc celle de l'outil qu'on paie déjà. Pas de compte, pas de télémétrie, fichiers .md bruts sur le disque, aucune base de données.

Gratuit, en anglais, chinois et japonais. Disponible pour macOS (Apple Silicon et Intel) et Linux (AppImage) ; la version Windows n'est pour l'instant qu'un éditeur, sans co-édition par agent. Réserve : le dépôt GitHub consulté est celui des versions publiées (https://github.com/OpenMarkdown-dev/OpenMarkdown-releases, 68 étoiles, dernière mise à jour le 3 novembre 2026) et GitHub n'y identifie aucune licence ; le site annonce « gratuit, et cela reste gratuit », mais le code n'est pas présenté comme libre — je le signale plutôt que de le supposer. Site : https://openmarkdown.dev/

Sketchy — retrouver le flux d'une application qu'on ne comprend plus

Outil pour le moment où l'on revient sur une application vibecodée et où l'on ne sait plus ce qui se passe après un clic. On demande à l'assistant de tracer le chemin « du bouton Enregistrer jusqu'à la base de données, et de montrer où cela peut échouer » : Sketchy dessine une carte interactive du flux, chaque nœud relié ouvrant le fichier source correspondant. Le principe est un partage des rôles : le modèle décrit la scène, Sketchy se charge de la disposition et du rendu — donc aucun jeton consommé pour placer les boîtes, et pas de chevauchement. Le dessin se retouche à main levée et s'exporte vers Excalidraw. Fonctionne dans Claude Code, Cursor et VS Code.

Licence MIT, gratuit. Dépôt : https://github.com/ddkbs/sketchy (144 étoiles, dernière mise à jour le 4 novembre 2026) — site : https://sketchy.davidkubus.dev

Hippocampus — une mémoire commune à toutes ses sessions d'agent

Mémoire persistante auto-hébergée pour Claude Code et les clients MCP : une seule mémoire pour toutes les sessions et toutes les machines. Le stockage est fait de simples fichiers Markdown, avec une recherche hybride (BM25, vecteurs locaux, graphe de connaissances) et un rappel automatique branché sur les crochets de l'agent, de sorte qu'il retrouve seul ce qu'il a appris auparavant. C'est le besoin le plus criant de ces outils — chaque nouvelle session repart de zéro — traité sans dépendre d'un service extérieur.

Licence MIT, gratuit. Dépôt : https://github.com/marcelinollima/hippocampus (5 étoiles, dernière mise à jour le 3 novembre 2026).

HelpPuff — un chat d'assistance pour son site, hébergé chez soi

Assistant de discussion à installer sur un site web, sur son propre compte Cloudflare et en une commande : le widget, une base de connaissances construite en lisant le site, et un tableau de bord des conversations et des contacts. L'installation par défaut tient dans l'offre gratuite de Cloudflare Workers. Intéressant pour qui veut une assistance sans confier le contenu de son site à un service tiers.

Licence MIT, gratuit. Dépôt : https://github.com/knowtific/helppuff (13 étoiles, dernière mise à jour le 2 novembre 2026) — page de présentation : https://knowtific.github.io/helppuff/

AIStoreHub — installer un serveur MCP sans écrire de JSON

Ligne de commande pour découvrir, installer et configurer des serveurs MCP dans Cursor, Claude Desktop et Windsurf, en supprimant la principale cause d'échec à la main : la virgule manquante dans le fichier de configuration et le chemin d'exécutable absent. Elle publie aussi ses propres systèmes et invite d'autres personnes à faire de même.

Licence MIT, gratuit, version 0.1.8 (26 octobre 2026), télémétrie anonyme désactivable. Paquet : https://pypi.org/project/aistorehub/ — registre : https://aistorehub.in

Deputy — laisser l'agent utiliser le navigateur où l'on est connecté

Donne à Claude Code, Codex, Gemini CLI, Copilot et Cursor l'usage du navigateur déjà ouvert, avec ses sessions, exposé comme des outils typés. Cela évite les impasses où l'agent échoue sur une page qui exige une connexion. Réserve : GitHub n'identifie pas de licence pour ce dépôt et il n'a qu'une étoile — projet très jeune, à regarder avant de l'installer.

Dépôt : https://github.com/RazinAI/deputy (1 étoile, dernière mise à jour le 22 octobre 2026).

Agent Tree — voir vivre les sous-agents dans un volet latéral

Programme en terminal qui affiche les agents d'une session Claude Code sous forme d'arbre mis à jour en continu et permet d'agir dessus : arrêter un sous-agent en cours, lui envoyer une nouvelle consigne au milieu de sa tâche, changer son modèle d'un clic, modifier l'affichage. Utile dès qu'une tâche se ramifie en plusieurs agents et que l'on perd le fil.

Licence MIT, gratuit. Dépôt : https://github.com/MikeGT4/agent-tree (16 étoiles, dernière mise à jour le 31 octobre 2026).

Arvre — naviguer entre les sessions et leurs embranchements

Petite interface en terminal (TUI) pour parcourir les sessions de Claude Code et leurs fourches, quand les tâches sont devenues trop nombreuses pour se souvenir de laquelle contient quoi. L'auteur reconnaît qu'il existe des outils voisins et assume l'avoir écrit en un week-end.

Licence MIT, gratuit. Dépôt : https://github.com/victorcarrico/arvre (1 étoile, dernière mise à jour le 3 novembre 2026).

Rexfeed — un fil d'actualité technique à côté de l'agent

Affiche de brèves cartes d'actualité technologique dans un volet latéral du terminal Rex pendant que l'agent travaille. Intérêt limité, mais l'idée de garder la veille sous les yeux pendant les temps morts d'une tâche est plaisante.

Licence MIT, gratuit. Dépôt : https://github.com/alpcanaydin/rexfeed (4 étoiles, dépôt mis à jour le 4 novembre 2026).

Clootee — installer Claude Code et Codex sans terminal

Paquet d'installation à décompresser et lancer d'un double-clic, qui se charge d'installer Node, Git et l'agent, puis ouvre une interface web pour la connexion et les sessions — l'objectif étant de supprimer les étapes qui bloquent un débutant. Prévu pour Windows, macOS et Linux ; l'interface n'est proposée qu'en anglais et en chinois, les téléchargements passent par un CDN chinois et le projet propose des modèles chinois (MiniMax, Kimi, MiMo) en repli.

Deux réserves sérieuses à connaître : le programme lance les moteurs avec les demandes d'autorisation désactivées — l'auteur écrit lui-même que quiconque peut ouvrir l'interface web peut exécuter n'importe quelle commande sur la machine, sous votre identité — et le dépôt n'a aucune étoile ni description. Licence Apache-2.0, gratuit. Dépôt : https://github.com/clootee/clootee

FormEase — compresser ses photos d'identité sans les envoyer ailleurs

Outil dans le navigateur, sans serveur, pour les cas où un portail administratif exige une photo d'identité sous 240 Ko ou une signature entre 10 et 20 Ko : recadrage biométrique, éclaircissement du fond de signature, compression au kilo-octet près en PDF ou JPG, entièrement en local (Canvas et Web Workers), avec un témoin de trafic réseau permettant de vérifier qu'aucune requête ne part après le chargement. Le raisonnement de l'auteur est juste : personne ne devrait téléverser son passeport sur un site de compression inconnu. Deux réserves : l'auteur ne dit pas que le code est publié (rien n'indique un logiciel libre), et la page m'a été inaccessible depuis ce serveur lors de la vérification — je n'ai donc pas pu contrôler l'application moi-même, seulement lire l'annonce.

Gratuit. Annonce et application : https://www.reddit.com/r/vibecoding/comments/1xnhs2u/

Lexique de design pour vibecodeurs — les mots justes pour se faire comprendre

Lexique ouvert des termes de mise en page et d'interface (grilles, verre dépoli, libellés segmentés…) avec de petites vignettes d'exemple, pour cesser de décrire à l'aveugle ce que l'on veut obtenir d'un modèle. L'auteur l'annonce gratuit, sans publicité ni péage, et cherche des contributions. Réserve : aucune adresse de dépôt n'est donnée dans le message, seulement le site — impossible de vérifier la licence.

Site : https://freedesignmd.com (onglet « Glossary »). Annonce : https://www.reddit.com/r/vibecoding/comments/1xndgxc/

Extensions et greffons

Roast Room — sept conseillers qui débattent d'une décision dans Claude Code

Le projet le plus suivi de cette sélection : sept personnages d'investisseurs et de dirigeants (dont Paul Graham et Warren Buffett, imités) débattent à table d'une décision d'entreprise, dans Claude Code. La valeur tient au procédé — faire jouer plusieurs rôles contradictoires plutôt que d'obtenir un avis unique — et les 1 855 étoiles montrent que l'idée parle. Dernier point de vigilance : le dépôt n'a pas bougé depuis le 22 octobre et sa licence n'est pas identifiée par GitHub.

Gratuit (il faut disposer d'un agent et de son abonnement). Dépôt : https://github.com/nateherkai/roast-room (1 855 étoiles, dernière mise à jour le 22 octobre 2026).

aido, intent-lens, fcc, Agent Trace, Spar, Harneo, Nexity, peekme, agent-analyzer

Neuf greffons ou extensions libres, tous publiés dans l'intervalle et tous liés au même écosystème d'agents de codage. Présentés brièvement, dans l'ordre d'arrivée :

  • aido — démarche « spécification d'abord, tests d'abord » pour Claude Code : l'agent écrit la spécification, le code et les demandes de fusion, l'utilisateur approuve chaque étape. MIT, dépôt créé le 31 octobre 2026, 4 étoiles, mis à jour le 4 novembre. https://github.com/joebew42/aido
  • intent-lens — voir ce que Claude Code s'apprête à faire avant qu'il ne le fasse ; extension rangée dans un ensemble de greffons maison. MIT, 1 étoile, mis à jour le 2 novembre. https://github.com/Dhananjay-JSR/claude-mods/tree/main/plugins/intent-lens
  • fcc (Flowchart for Claude Code) — après chaque tâche, un récit en langage simple de ce qui a changé et un organigramme de comportement ancré dans le code, conservé dans le dépôt. Licence MIT, mais attention : rien n'a bougé depuis le 25 septembre 2026. https://github.com/alexabbi/fcc
  • Agent Trace — met l'historique local de Codex et de Claude Code à disposition des agents (résumés ou conversations complètes), sous forme de serveur MCP. Apache-2.0, 1 étoile. https://github.com/wcook04/agent-trace-mechanism
  • Spar — fait s'opposer Claude et ChatGPT jusqu'à obtenir une réponse solide, en s'appuyant sur les abonnements déjà payés plutôt que sur une clé d'API supplémentaire. Apache-2.0, dépôt créé le 3 novembre 2026. https://github.com/spar-ai-app/spar
  • Harneo — bibliothèque unique de compétences, sous-agents, réglages et serveurs MCP, installable dans n'importe quel projet sous forme de profil, chaque écriture étant prévisualisée et sauvegardée. MIT, 2 étoiles. https://github.com/ibrahimkobeissy/harneo
  • Nexity — compétences pour ajouter des sections à un site Next.js et Sanity ; utile seulement si l'on travaille sur cette pile précise. MIT, 14 étoiles. https://github.com/Pagepro/nexity
  • peekme — sélectionner du texte dans le terminal de l'agent pour obtenir une courte explication juste en dessous, ou poser sa propre question. Apache-2.0, 7 étoiles. https://github.com/GregoryBolshakov/peekme
  • agent-analyzer — greffon qui repère le travail que l'agent répète, ce qu'il coûte et comment y remédier ; les sessions sont nettoyées sur la machine avant tout envoi. Apache-2.0, 2 étoiles. https://github.com/revefi/agent-analyzer
