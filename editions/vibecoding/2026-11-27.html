En bref

Nextcloud sort sa version bureau de son suite bureautique open source. SeaHelm propose une application macOS native pour exécuter des agents Claude Code en parallèle. Moat se présente comme un remplacement d'OpenRouter pour réduire les coûts.

Applications et outils nouveaux

SeaHelm — espace de travail natif macOS pour les agents Claude Code
SeaHelm est une application macOS native construite autour de Ghostty qui offre un roster de worktrees Git et un agent par split-pane. Chaque worktree correspond à une ligne du roster et les sessions persistent via zmx. Idéal si vous gérez plusieurs projets simultanément avec des agents Claude Code. Dépôt BetaYao/seahelm (Rust, 23 étoiles, dernier push 26/11/2026). Gratuit.

Torno — établi de bureau pour fabriquer des pièces CAO avec un agent IA
Torno permet de créer des pièces CAO en pointant vers le modèle et en laissant l'agent écrire le code build123d ;torno reconstruit la pièce à chaque sauvegarde. C'est un atelier de fabrication assistée par IA dédié à la modélisation CAO paramétrique. Dépôt luisg0nc/torno (TypeScript, 11 étoiles, dernier push 26/11/2026). Gratuit.

Lip-Dictation — dictation silencieuse pour Claude Code via lecture des lèvres locale
Lip-Dictation permet de faire parler un modèle de reconnaissance des lèvres installé localement devant votre webcam : les mots tapés directement dans le prompt de Claude Code, sans microphone. Une approche originale pour coder sans bruit. Dépôt batanus/lip-dictation (TypeScript, 7 étoiles, dernier push 26/11/2026). Gratuit.

Moat — remplacement OpenRouter pour les appels à grands modèles
Moat se positionne comme un replace d'OpenRouter pour accéder aux mêmes modèles de grandes capacités. Présenté comme une alternative moins chère, il vise les développeurs qui cherchent à réduire leurs coûts d'appels API tout en conservant l'accès aux frontier models. Site commandcode.ai/moat.

Draftmux — polir le texte écrit par votre agent de codage avant qu'il ne parte
Draftmux est un outil de relecture et de polissage automatique des textes générés par un agent de codage avant leur diffusion. Il intervient entre la sortie brute de Claude Code et le message envoyé — email, ticket, documentation. Site draftmux.raine.dev.

AgentDesign — dessiner chaque écran avant que l'agent de codage n'écrive
AgentDesign fait intervenir l'agent IA pour dessiner chaque écran de l'application avant même d'en coder la logique. L'idée : valider visuellement l'interface utilisateur avant de passer au développement, ce qui évite les boucles de correction coûteuses. Site getagentdesign.com.

Minipg — PostgreSQL et SQLite réunis en un seul exécutable portable
Minipg combine les fonctionnalités de PostgreSQL et de SQLite en un seul exécutable statique écrit en Zig. Idéal pour distribuer des applications avec une base de données relationnelle complète, sans dépendance système ni installation séparée. Dépôt progrium/minipg (Zig, 204 étoiles, dernier push 26/11/2026). Gratuit.

Safer-dependencies — couche de sécurité pour Claude Code
Safer-dependencies audite les paquets avant qu'ils ne soient ajoutés au projet par Claude Code. Il détecte et corrige les dépendances risquées : CVE connues, typosquats, paquets abandonnés, problèmes de version. Couvre npm, PyPI, RubyGems, Maven, Go et Rust. Dépôt robert-auger/safer-dependencies (Python, 46 étoiles). Gratuit.

Openfal — génération d'images et vidéos locales via une API style fal
Openfal offre un serveur local de génération d'images et de vidéos exposant une API compatible avec le protocole fal. Permet d'intégrer la génération multimodale dans des pipelines de développement sans dépendre d'un service cloud. Site openfal.org.

Nouveautés et mises à jour

Nextcloud Office Desktop — Nextcloud lance une application bureau pour sa suite bureautique collaborative. La nouveauté génère beaucoup d'intérêt sur Hacker News (348 points, 150 commentaires). L'approche consiste à rapprocher la bureautique web du poste de travail, avec synchronisation continue via Nextcloud. Article sur nextcloud.com.

llama.cpp — benchmarks AMD Ryzen et Radeon — HuggingFace publie un tableau de bord de benchmarks spécifique pour les processeurs AMD dans llama.cpp. Ce suivi aide les utilisateurs AMD à suivre les performances de chargement et d'inférence des modèles locaux. Blog huggingface.co/blog/ggml-org/llamacpp-amd-bench.
