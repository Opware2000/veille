Veille r/vibecoding — lundi 16 novembre 2026

En bref

La nuit a surtout produit des outils de développeur : un éditeur de dessin piloté par l'agent (Klad), un éditeur LaTeX en terminal (Texo) et un vérificateur d'annotations Python (Gawain), tous libres ou à source disponible. Côté agents, Claude Code reçoit un mode d'exécution expérimental (« Code Mode ») tandis qu'OpenAI annonce l'abandon du mode plan de Codex. Les plugins Datasette de Simon Willison reviennent avec le support des points d'accès compatibles OpenAI, ce qui ouvre le pilotage de Datasette par un modèle local.

Applications et outils nouveaux

Klad — un logiciel de peinture que votre agent pilote en ligne de commande. Application de dessin et d'animation 2D écrite en Rust, dont toutes les fonctions sont exposées en ligne de commande : l'agent pose les traits un par un, et chaque trait reste modifiable ensuite par vous ou par lui. Le fichier de dessin est un fichier ordinaire, donc différable et versionnable comme du code ; l'interface graphique sert d'éditeur complet (calques, moteur de pinceaux, vecteur, ligne, pixel art, animation). L'auteur assume un choix intéressant : aucun modèle d'image n'est embarqué, l'outil ne sert qu'à donner des pinceaux à l'agent, ce qui évite les re-générations aléatoires. Le dépôt affiche 270 étoiles et une licence non standard — le code est consultable mais ce n'est pas une licence libre reconnue, et il n'y a pas encore d'installeur : il faut compiler depuis les sources, le dessin sous Windows étant non testé. Dépôt : https://github.com/klad-app/klad — site : https://klad.studio

Texo — un éditeur et gestionnaire de CV LaTeX en terminal. Application en terminal pour écrire, compiler et gérer plusieurs CV LaTeX, avec une aide facultative : on peut demander la réécriture d'une section ou l'adaptation du CV à une offre, prévisualiser le PDF, puis accepter, corriger ou abandonner la proposition. L'éditeur LaTeX, l'aperçu PDF et la conversation avec le modèle vivent dans le même espace de travail ; mode Vim, historique de révision et jeux de CV séparés selon le type de poste sont prévus. C'est un projet jeune, en Rust, qui annonce macOS et Linux et se dit libre, mais GitHub ne reconnaît pas la licence déposée : à vérifier avant de s'y engager. 10 étoiles, dernière activité le 14 novembre 2026. Dépôt : https://github.com/hexaquarks/texo

Ductus — transformer son écriture en police de caractères. L'outil se présente comme un questionnaire guidé : on écrit chaque lettre dans une case (les vingt-six minuscules, puis les majuscules), la page vérifie la reconnaissance, puis exporte la police. Le traitement se fait entièrement dans le navigateur, aucune lettre n'est envoyée à un serveur — c'est écrit noir sur blanc sur la page, ce qui est le bon argument pour un usage scolaire. Sujet très discuté sur Hacker News (78 points, 17 commentaires). Je n'ai trouvé ni dépôt de code, ni licence, ni mention de prix sur le site : il reste donc à vérifier sur place si l'export est librement utilisable. Adresse : https://ductus.sorenblank.com

cbooks — un lecteur d'EPUB libre et gratuit dans le navigateur. Le lecteur fonctionne hors ligne, garde les notes et la position de lecture sur l'appareil, et ajoute un « plan de lecture » (les chemins suivis d'un livre à l'autre, fusionnables et sauvegardables). L'auteur l'a fait construire par Claude faute de lecteur qui lui convenait, et fournit deux livres d'exemple — dont un petit manuel sur le codage assisté de jeux. Le lecteur est annoncé gratuit et s'appuie sur la bibliothèque libre foliate-js. Deux réserves : il est servi depuis une adresse personnelle (friendsservermb.mine.nu) sans dépôt de code public annoncé, donc sa pérennité n'est pas garantie, et je n'ai pas pu vérifier de licence. Adresse : https://friendsservermb.mine.nu/cbooks/

Kiri — un moteur de conteneurs présenté comme alternative à Docker Desktop. Il exécute les conteneurs Docker avec un seul démon, en conservant la compatibilité avec la ligne de commande docker, Compose, l'API Docker et les images OCI. L'éditeur annonce des démarrages huit fois plus rapides que Docker Desktop sur la même machine (mesure maison : 22 ms pour un docker run contre 178 ms, et il cite Colima à 152 ms et OrbStack à 279 ms), une fenêtre traduite en quinze langues et une prise en charge de Kubernetes. Gratuit pendant la version bêta sur macOS, Windows et Linux, mais le code n'est pas publié : c'est un logiciel propriétaire, ce qui est une réserve réelle pour un usage durable. Site : https://runkiri.com/

Gawain — imposer l'annotation de tous les types en Python. Le projet part d'un constat précis : mypy, Pyright, ty et pyrefly déduisent le type d'une variable non annotée, si bien qu'une base de code peut passer tous les contrôles sans qu'aucun type ne soit écrit. Gawain exige donc une annotation sur les variables, les paramètres, les valeurs de retour et les attributs de classe, puis lance ty ou pyrefly pour vérifier que ces types sont justes. Publié sur PyPI, en Rust, license MIT, 41 étoiles, dernière activité le 15 novembre 2026. Dépôt : https://github.com/matheuzgomes/gawain

Yarrow — une bibliothèque de correctifs partagée entre agents. Avant qu'un agent ne perde vingt minutes sur une erreur, il vérifie si un autre agent a déjà résolu le problème : 52 erreurs courantes y sont recensées (erreurs use client de Next.js, RLS Supabase qui bloque une insertion, Prisma sur Vercel, perte de session au rafraîchissement, variables d'environnement Vite). Vingt correctifs ont été prouvés en bac à sable — projet cassé reconstruit, erreur reproduite, correctif appliqué, test relancé — les autres sont marqués non vérifiés, ce que l'auteur dit honnêtement. L'installation se fait en une ligne et l'outil s'ajoute à Claude Code, Cursor, Codex ou tout agent compatible MCP ; il est gratuit, l'éditeur vendant par ailleurs des « salons d'équipe ». Adresse : https://yarrow-fixes.vercel.app

Codex dans la barre de menus du Mac. Une petite application Swift qui suit les sessions Codex depuis la barre de menus, faite par un développeur qui ne voulait plus courir après les notifications. 0 étoile et licence non reconnue par GitHub à cette heure : c'est une nouveauté que personne n'a encore remarquée, à essayer avec prudence. Dépôt : https://github.com/smol-ninja/little-brain

AutoSize — comparer les dimensions de voitures. Site gratuit qui présente côte à côte longueur, largeur, largeur avec rétroviseurs, hauteur, garde au sol, volume de coffre, places, points ISOFIX, poids, consommation, autonomie électrique et résultats Euro NCAP, avec des filtres par gabarit, nombre de places et budget de coffre. Utile pour vérifier qu'un véhicule entre dans un garage ou qu'il accepte deux sièges enfants. Le site ne publie ni code ni licence : la base de données est propriétaire. Adresse : https://www.autosize.org/

Brabble — un agrégateur de hackathons et de concours. Le site rassemble 951 annonces en cours provenant de vingt-deux sources (Devpost, Devfolio, MLH, Kaggle, Codeforces, CodeChef, AtCoder, Hack Club…), permet de filtrer selon ce à quoi on est éligible et propose un abonnement de calendrier qui met chaque échéance dans son agenda avec un rappel la veille, sans compte ni adresse électronique. Le site annonce être lui-même libre et propose d'ailleurs un concours « open source ». Adresse : https://brabble.ai

Fireface UCX sous Linux — pilote et table de mixage en terminal. RME n'a jamais publié le protocole de son interface Fireface UCX ; un développeur l'a fait analyser par Claude Code à partir du pilote Windows, puis a vérifié les conclusions contre le matériel réel. Le résultat est libre (licence MIT) : un pilote noyau, une table de mixage en terminal et les outils autour, avec 3,5 ms d'aller-retour à 48 kHz sous PipeWire. Cela ne concerne que les possesseurs de cette interface — dont vous ne faites probablement pas partie — mais le procédé, faire rétroconcevoir un protocole fermé pour libérer un matériel, mérite d'être connu. 3 étoiles, dernière activité le 15 novembre 2026. Dépôt : https://github.com/realbogart/fireface-ucx-linux

Tunnel to My Dash — un tunnel WireGuard interne à l'application. L'application ouvre son propre tunnel WireGuard en espace utilisateur : seule la session de navigation qu'elle contient passe par le réseau domestique, le VPN système reste intact, et il n'y a ni droits administrateur ni « slot » VPN à occuper. Annoncée pour Linux, Windows et Android. Incertitude à signaler : le message ne donne aucune adresse de site ni dépôt public, et je n'en ai trouvé aucun — l'outil existe donc surtout à l'état d'annonce, et je ne peux pas vérifier sa licence ni son prix. Message d'origine : https://www.reddit.com/r/vibecoding/comments/1xwjn5y/i_built_an_appowned_wireguard_tunnel_that_opens/

Nouveautés et mises à jour

datasette-llm 0.1a11 accepte les points d'accès compatibles OpenAI. C'est le greffon intermédiaire qui configure les modèles pour tous les autres greffons Datasette : il peut désormais pointer vers un service local ou distant qui parle le protocole d'OpenAI, ce qui permet de faire tourner Datasette Agent sur un modèle servi par LM Studio, Ollama ou llama.cpp (dont la bibliothèque ggml passe justement en version 1.0.0). Un exemple complet est donné en ligne de commande. Licence Apache 2.0, 20 étoiles, publication du 14 novembre 2026. Dépôt : https://github.com/datasette/datasette-llm/releases/tag/0.1a11

datasette-vega 0.7, première publication depuis 2018. Le plus ancien greffon de dataviz de Datasette — des graphiques Vega-Lite sur une table ou une requête — ressort pour rester compatible avec les versions alpha récentes, et fonctionne maintenant dans Datasette Lite, qui sait exécuter des greffons JavaScript. Licence Apache 2.0, 65 étoiles, 14 novembre 2026. Dépôt : https://github.com/simonw/datasette-vega/releases/tag/0.7

Claude Code ajoute un « Code Mode » expérimental. Au lieu d'enchaîner des appels d'outils un par un en attendant chaque résultat, Claude écrit un morceau de JavaScript qui regroupe plusieurs appels en une seule étape. C'est une modification du fonctionnement même de l'agent, avec ses limites et ses réglages d'organisation documentés. Documentation : https://code.claude.com/docs/en/code-mode

Codex va abandonner son mode plan. Un ingénieur d'OpenAI l'a écrit noir sur blanc dans un fil de suivi du dépôt : « nous abandonnerons bientôt le mode plan, nous ne prévoyons donc plus d'y investir ». Si vous avez bâti des habitudes autour de ce mode, c'est le moment de prévoir la transition. Source : https://github.com/openai/codex/issues/18490#issuecomment-6890525683

Extensions et greffons

claude-cyberpunk-themes — sept thèmes animés pour l'application de bureau de Claude Code. Chaque thème pose une scène pixel art animée derrière la conversation et recolore l'application ; n'utilise que des SVG sans script, ne touche ni au réseau ni aux fichiers et ne mémorise que le thème choisi. Fonctionne uniquement dans l'onglet Code de l'application de bureau. Licence MIT, 3 étoiles, actif le 15 novembre 2026. Dépôt : https://github.com/nocashflow/claude-cyberpunk-themes

claudette — faire tourner Claude Code sur les modèles Mistral. Un greffon en Python qui branche Claude Code sur les modèles de Mistral, obéissant à la même logique de choix de fournisseur et de coût que le reste de votre outillage. Licence MIT, 4 étoiles, 15 novembre 2026. Dépôt : https://github.com/raed667/claudette

hook-me-up — répondre à Claude Code depuis les notifications de macOS. Un outil en Swift qui transforme les notifications natives du Mac en point de réponse : on approuve une permission, on répond à une question ou à un plan, et on sait quand une session se termine, sans revenir dans le terminal. Installation en une ligne annoncée. Licence MIT, 2 étoiles, actif le 15 novembre 2026. Dépôt : https://github.com/robertodf99/hook-me-up
