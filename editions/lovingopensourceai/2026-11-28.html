Applications et outils nouveaux

Ladybird — premier alpha d'un navigateur web indépendant

Le projet libherald (SerenityOS) publie son premier alpha téléchargeable de Ladybird, le navigateur écrit depuis zéro en C++ avec le framework Qt/KDE. Il s'agit d'une implémentation non-Chromium d'un moteur de rendu web destiné à remplacer le moteur hérité de SerenityOS. Les premiers tests montrent une capacité surprenante à afficher des pages complexes, même si de nombreuses fonctionnalités restent à implémenter. Un projet ambitieux qui pourrait, à terme, offrir une alternative réelle aux moteurs Blink et Gecko. Voir aussi l'article d'Ars Technica sur les capacités observées.
Licence : BSD-2-Clause. Gratuit. https://www.theregister.com/software/2026/11/26/indie-web-browser-ladybird-enters-alpha-testing/5311914

DietPi — nouvelle version 10.9

La distribution légère basée sur Debian pour micro-ordinateurs (Raspberry Pi, systèmes embarqués) et serveurs sort sa version 10.9. DietPi se distingue par son image minimale et ses scripts d'installation automatisés via dialog console pour déployer des piles logicielles complètes en quelques clics. La licence est GPL-2.0, le dépôt compte environ 6 500 étoiles.
https://github.com/MichaIng/DietPi/releases

rVoip — pile VoIP écrite en Rust

Projet publié sur Hacker News (67 points, 15 commentaires), rVoip propose une pile VoIP complète développée en Rust. L'objectif est de fournir une solution moderne, sûre (garanties de sécurité mémoire grâce à Rust) et performante pour la communication voix sur IP. Compatible MIT.
https://github.com/eisenzopf/rvoip

F_data_brokers.py — supprimer ses données des courtiers*

Script Python publié sur GitHub et popularisé sur Hacker News (plus de 200 points). L'outil automate l'envoi de demandes de suppression conforme au GDPR auprès des principaux courtiers de données personnels, permettant aux utilisateurs de réclamer leurs informations détenues par ces entreprises. Licence MIT, près de 630 étoiles.
https://github.com/gary23w/f-ck_data_brokers

Lantern Promos — serveur MCP pour codes promotionnels

Serveur MCP (Model Context Protocol) permettant à des agents IA de vérifier automatiquement la disponibilité de codes promo dans les boutiques en ligne. Outil utile pour tout écosystème intégrant un agent capable de rechercher les meilleures offres avant un achat. Site disponible gratuitement (modèle à confirmer).
https://lanternpromos.com/
