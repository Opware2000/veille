Applications et outils nouveaux

Minipg — PostgreSQL en un seul exécutable

Minipg embarque PostgreSQL dans un fichier binaire autonome. Pas de serveur à configurer, pas de daemon en arrière-plan : une archive .pgdb contient les données, la configuration et le mot de passe superutilisateur. À chaque commande, minipg lance Postgres via h9 (une bibliothèque Zig qui fait tourner des binaires Alpine sur un micro-noyau Plan 9), l'utilise, puis l'éteint quand il n'est plus utilisé. Un lock assure qu'un seul processus tourne par base.

Disponible pour Linux x86_64 (KVM ou mode natif sans /dev/kvm), macOS Apple Silicon et même dans un navigateur WebAssembly. La licence est MIT, l'exécutable pèse environ 35 Mo en téléchargement.

progrium/minipg — 202 étoiles, licence MIT, dernière mise à jour le 26/11.

OpenFal — Serveur local compatible fal.ai pour la génération d'images et vidéo

OpenFal fournit une API HTTP compatible avec fal.ai pour faire tourner localement Qwen-Image-2.1, Wan 2.2 et MiniMax H3 (génération vidéo, face swap, audio stéréo). Contrairement à ComfyUI, on évite les graphes de nœuds : un CLI détecte le matériel, télécharge les poids vérifiés, et met en place un point de terminaison local, un queue manager et un Studio web.

Le runtime utilise le block-offloading PyTorch plutôt que le continuous batching — c'est séquentiel au lieu de concurrent, ce qui convient aux GPU grand public où la mémoire peut être juste. Compatible Windows, Linux et macOS.

License MIT, dépôt créé le 16/11.
esokullu/openfal — site : https://openfal.org

RustingStrata — Moteur GGUF Rust, modèles > VRAM sur CUDA et Vulkan

RustingStrata est un moteur d'inférence LLM écrit en pur Rust, capable de charger des modèles GGUF plus volumineux que la VRAM disponible grâce à un système de tiering entre GPU et RAM hôte. Supporte CUDA et Vulkan comme accélérateurs matériels. Déjà près de 500 étoiles en quelques jours seulement.

Le projet vise les développeurs Rust qui souhaitent intégrer l'inférence locale directement dans leurs applications sans passer par Python. Licence NOASSERTION (à vérifier).
RustingStudio/RustingStrata — 495 étoiles, dernière mise à jour le 26/11.

Please — LLM de dialogue dans le terminal, inférence locale

Please est un outil en ligne de commande qui permet de décrire en langage naturel des opérations sur le répertoire courant (résumer des commits, générer des scripts, formater du code, résoudre des conflits Git). Tout le traitement reste local sur la machine — les weights Inkling-2-Mini-IQ4_NL sont téléchargés une fois et réutilisés. Une fonctionnalité SSH « bridging » permet de s'y connecter depuis un shell distant ou un conteneur Docker sans recopier les poids.

Disponible via Homebrew ou un script d'installation. Écrit en Ruby + Rust + Shell.
xhjkl/please — 26 étoiles, dernière mise à jour le 25/11.

DhurandharAI — Exécuter des modèles GGUF offline sur Android

Une application Android pour faire tourner des modèles GGUF en local sur téléphone, sans connexion internet. Destinée aux utilisateurs qui veulent accéder à un assistant IA hors ligne sur mobile.

ZeroBurn — Réduire la consommation de tokens des agents de codage

ZeroBurn réduit la combustion de tokens des agents de programmation grâce à un mode MCP zéro token couplé à Ollama en local. Annoncé comme permettant jusqu'à 98 % d'économie de tokens sur les tâches d'agent.

Nouveautés et mises à jour

Intel publie la police Mono One

Intel a rendu publique sa police de caractères mono espacement One, sous licence Apache 2.0. Conçue pour la lecture de code, elle vise à remplacer les fontes propriétaires ou celles avec licences restrictives dans les environnements de développement. Cette publication complète la gamme de polices proposées précédemment par Intel Design Font Foundry.
github.com/intel/intel-one-mono

Correctifs spécifiques AMD pour llama.cpp

Des correctifs ciblés pour les processeurs AMD ont été publiés dans le cadre de llama.cpp. Ils activent des instructions AVX512 non supportées par défaut sur certains chips Ryzen, améliorant significativement les performances sur les architectures AMD modernes.
davidbau/amd-specific-llama-cpp — 45 points sur HN, 6 commentaires.

OS bare-metal pour Qwen3-0.6B

Un système d'exploitation bare-metal exécutant Qwen3-0.6B est annoncé, affichant des performances 54 % supérieures à llama.cpp. Le projet, issu des travaux d'alesha-pro (connu pour les benchmarks de latence de modèles), démontre qu'en supprimant toute couche d'abstraction (hyperviseur, kernel Linux), l'inférence LLM peut atteindre des vitesses très proches du matériel nu.
@superalesha
