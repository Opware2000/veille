En bref

Un benchmark de modèles TTS ouverts sur CPU, une technique d'adaptation par RL pour les harnais d'agents, et un nouveau plugin de détection de mot-clé vocal pour remplacer openWakeWord.

Applications et outils nouveaux

Small TTS Bench — classement des modèles de synthèse vocale ouverts sur CPU. Eren Gölge publie un banc d'essai de 21 modèles TTS à poids ouverts, mesurés sur un seul thread CPU : latence de première audio, vitesse (× temps réel), mémoire, taux d'erreur et naturalité (UTMOS). Phonon 31m (Apache-2.0, via le moteur ptts) se distingue comme meilleur compromis : 82 ms de première audio, 4× temps réel, 363 Mo, 1,6 % WER, 4,43 UTMOS. PiVo-1.4M (Apache-2.0) offre la plus faible latence (5 ms) pour 147 Mo. Tous les échantillons audio et le classement sont en ligne. Lien : https://erogol.com/small_tts_bench/

Harness adapters — des adaptateurs LoRA entraînés par RL pour chaque harnais d'agent. Hugging Face publie une recette reproductible pour entraîner, par RL dans le harnais cible, un adaptateur LoRA qui spécialise un modèle (Qwen3.8-27B) sur un harnais particulier (pi, Hermes Agent, OpenCode). Résultat : jusqu'à 55 % pass@1 sur Terminal-Bench (contre 39 % sans), avec une consommation de tokens réduite de moitié (1 500 au lieu de 2 900 par tâche). Les trois adaptateurs sont fusionnables en un super-adaptateur unique. Tous les artéfacts (LoRA, GGUF, tâches RL) sont publiés sur le Hub sous licence ouverte. Lien : https://huggingface.co/blog/harness-adapters-at-scale

Nouveautés et mises à jour

Platypush — assistant vocal local : migration vers microWakeWord. Fabio Manganiello remplace le plugin openWakeWord (abandonné, modèles de 2023) par assistant.microwakeword, basé sur microWakeWord — le moteur utilisé par ESPHome et Home Assistant Voice. Les modèles intégrés (okay_nabu, hey_jarvis, alexa) sont livrés avec le paquet, plus robustes et mieux entretenus. Le nouveau plugin expose la même API que l'ancien : la migration se fait en changeant le nom du plugin dans la configuration. microWakeWord : dépôt GitHub (39 ★, Apache-2.0). Lien : https://blog.platypush.tech/article/Rewriting-my-voice-assistant-pipeline
