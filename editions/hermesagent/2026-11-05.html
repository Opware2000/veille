Applications et outils nouveaux

Dots-hermes — l'agent Hermes dans une messagerie Android

Application Android native (Kotlin) écrite par Drevero, présentée comme l'équivalent libre du compagnon « Dots » : l'interface d'un assistant de poche, mais reliée à l'agent Hermes que l'on fait déjà tourner soi-même, avec ses compétences, sa mémoire et ses tâches planifiées.

Ce qu'elle apporte concrètement : accès direct depuis le téléphone sans ouvrir de terminal ; accusés de réception, réactions et Markdown riche (tableaux, blocs de code avec bouton de copie, listes à cocher) ; historique qui se charge au fil du défilement ; messages rédigés hors ligne envoyés dès le retour du réseau. Les compétences lues et les commandes exécutées s'affichent dans un bandeau discret au-dessus de la réponse, avec durées et échecs, plutôt que d'encombrer la conversation. Les commandes sensibles attendent une approbation que l'on peut donner ou refuser depuis la notification, sans ouvrir l'application ; les questions de clarification arrivent sous forme de boutons. Notes vocales dans les deux sens.

Licence GPL-3.0, gratuit, code source ouvert. Le dépôt compte 22 étoiles et 2 duplications, créé le 3 novembre 2026, dernier envoi le 4 novembre : projet très jeune, à essayer en connaissance de cause.

Lien : https://github.com/Drevero/Dots-hermes

hermes-linkedin-jobsearch — un agent qui postule à votre place

Dépôt Python sous licence MIT (2 étoiles, 3 tickets ouverts, créé le 19 octobre 2026, dernière mise à jour le 4 novembre) : l'agent cherche les offres d'emploi, se renseigne sur les entreprises, adapte le curriculum vitae à chaque annonce, postule et suit les candidatures. C'est l'automatisation décrite dans le fil Hacker News « Hermes: A job-search agent that applies for you » (2 points, 1 commentaire — donc peu vu).

Incertitude : je n'ai pas exécuté l'outil et rien ne permet de dire si les candidatures automatiques fonctionnent réellement sur les plateformes visées ; le dépôt est récent et peu suivi.

Lien : https://github.com/shbernal/hermes-linkedin-jobsearch
