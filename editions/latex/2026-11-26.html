La fermeture de l'espace de travail LaTeX Prism d'OpenAI au 1er janvier suscite des débats sur la dépendance aux outils hébergés. Le moteur TeXyoN, écrit en Rust, publie son code source avec aperçu en direct et extension VS Code. Une mise à jour de TeXstudio introduit un bogue de saisie à éviter.

Paquets, classes et outils nouveaux

TeXyoN — Moteur TeX pour aperçu en direct (code source ouvert)

Le projet TeXyoN (dénommé ainsi en référence à la tachyon, particule hypothétique plus rapide que la lumière) est un moteur TeX written entirely in Rust conçu pour rafraîchir les changements aussi vite que possible. Il vient de publier son code source complet, accompagné d'un billet détaillant les décisions d'architecture, des benchmarks de performance et une liste de bugs connus. Le projet inclut également une extension VS Code et un paquet npm compilant le moteur en WASM pour créer des expériences interactives dans le navigateur. L'auteur a comparé la sortie de compilation complète sur plus de 9 000 documents avec TexLive ; il indique une compatibilité très élevée bien que certaines limitations subsistent en version initiale.

  • Dépôt : https://github.com/texyon-org/texyon
  • Billet technique : https://yendric.be/introducing-texyon/
  • Extension VS Code : https://marketplace.visualstudio.com/items?itemName=texyon.texyon-live-preview
  • Paquet npm : npm install texyon

Nouveautés et mises à jour

TeXstudio 4.9.9 — Bogue de saisie des accolades. En mettant à jour depuis la version 4.9.7, TeXstudio 4.9.9 ne ferme plus automatiquement l'accolade gauche { au-dessus du texte sélectionné : au lieu d'entourer le texte, il remplace celui-ci par {. Les autres symboles (), [], \left{ \right} conservent leur comportement attendu. Un correctif est attendu. Si vous utilisez cette version, faites attention lors de la saisie d'environnements ou de macros entre accolades.

Overleaf — Article sur la numérisation de documents accessibles dans les bibliothèques académiques. Overleaf publie un article de synthèse reprenant les études de cas rapportées dans la première section d'un article publié dans le Journal of eScience Librarianship (del Junco et al. 2026), qui recueille les retours de bibliothécaires universitaires (University of Oklahoma, Princeton University, KAUST) sur leurs pratiques d'enseignement de LaTeX. Pour les chercheurs ou enseignants souhaitant s'appuyer sur des méthodes éprouvées, les liens vers les études originales sont fournis dans l'article.

  • Article Overleaf : https://www.overleaf.com/blog/twelve-libraries-teach-latex-heres-what-they-have-in-common-overleaf

Astuces et gabarits réutilisables

Beamer — Spécifier l'encodage T1 pour une police de titre uniquement. Une question récente sur TeX Stack Exchange montre comment contourner une limitation de Beamer : lorsqu'on utilise \setbeamerfont pour appliquer une police personnalisée (comme Oswald) aux titres de diapositive, l'encodage de police défini au niveau de la présentation (\setbeamerfont) n'est pas toujours appliqué correctement si la police ne charge pas son encodage via le mécanisme fontspec. La solution consiste à utiliser \fontencoding{T1}\usebeamerfont{title} directement dans le contenu ou à définir des fontes fixes via \DeclareFixedFont pour chaque taille de titre désirée. Cette astuce s'applique à toute présentation nécessitant une police différente de celle du corps du texte.

Prism d'OpenAI — Liste de vérification pour l'export. Les utilisateurs de Prism doivent exporter leurs projets avant le 1er janvier 2027. L'export se fait via Paramètres → Contrôles de données → Exporter tous les projets. Il est recommandé de télécharger ensuite chaque projet individuellement en mode PDF, de vérifier que la version exportée correspond au fichier original, et de conserver les fichiers .tex, figures et .bib. L'historique, les commentaires en ligne et les liens Zotero ne sont pas transférables.
