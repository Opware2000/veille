Paquets, classes et outils nouveaux

TeXyon — moteur TeX de bureau pour l'aperçu direct

Yendric a publié le code source de TeXyon, un moteur TeX écrit entièrement en Rust et conçu dès l'origine pour afficher les modifications aussi rapidement que possible. Le projet accompagne son lancement d'un article technique détaillant les décisions architecturales, de benchmarks comparatifs et d'une liste de bugs connus. Trois livrables sont mis à disposition :

  • Moteur natif — binaire unique compilé depuis Rust, exécutable localement sur macOS, Linux et Windows ;
  • Extension VS Code — démontre le moteur en action via une intégration native ;
  • Paquet npm — compile TeXyon en WebAssembly et expose une API simple pour créer des expériences TeX interactives dans un navigateur.

L'auteur a validé la fidélité de compilation sur plus de 9 000 documents tirés de TexLive en amont. Début de projet, bogues attendus — les rapports se font sur le dépôt GitHub.

Licence : MIT. Dépôt : github.com/texyon-org/texyon · 17 étoiles. Article de présentation : yendric.be/introducing-texyon.

Snippai — extraire du LaTeX d'une capture d'écran grâce à l'IA

Outil open-source permettant de convertir des captures d'écran contenant des formules ou du code vers LaTeX, Markdown ou réponses textuelles. Utilise l'intelligence artificielle pour lire le contenu visuel et restituer du code exploitable directement. Communauté importante (près de 2 000 étoiles sur GitHub). Licence : AGPL-3.0. Dépôt : github.com/xyTom/snippai.
