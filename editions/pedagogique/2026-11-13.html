Gratuit : https://drane.region-academique-idf.fr/article662.html

Pad public, outil libre de La Digitale : https://digipad.app/p/1859891/8a101ba6cbf708
  • Yandex Cloud : 2,84 % des données clients définitivement perdues après des frappes (developpez.com, 12/11) — la société confirme que des données sont irrécupérables, faute de sauvegardes exploitables ; bon argument à ressortir auprès des collègues qui déposent leurs seules copies sur un espace en ligne. https://cloud-computing.developpez.com/actu/389010/Les-frappes-de-l-Ukraine-entrainent-une-perte-definitive-de-donnees-sur-le-cloud-russe-Yandex-irrecuperables-en-raison-de-dommages-critiques-aux-equipements-et-de-l-absence-de-sauvegardes/
  • Ntfy : un point d'entrée unique pour ses notifications (Journal du hacker, 10/11) — serveur de notifications auto-hébergé, installable chez soi, qui regroupe les alertes de tous ses scripts et services sur téléphone ou bureau : la brique pratique pour être prévenu sans dépendre d'un service tiers. Gratuit, open source : https://domopi.eu/mise-en-place-de-ntfy-un-point-dentree-unique-pour-toutes-vos-notifications/
  • Flus 3.0 (LinuxFr, 5/11) — l'agrégateur de flux RSS/ATOM libre et français passe en 3.0 : de quoi rapatrier ses veilles hors des réseaux et des plateformes, en gardant ses propres filtres. Gratuit, open source : https://linuxfr.org/news/flus-sort-en-3-0

2. IA pour le développement

  • Modern Web Guidance (Korben, 12/11) — un « skill » porté par les équipes Chrome, Edge, Firefox et MDN : il donne à votre agent un catalogue des primitives natives du web moderne (<dialog>, Popover API, container queries, passkeys, CSP…) pour qu'il arrête de générer des pages de JavaScript là où le navigateur sait faire seul. Gratuit, open source : https://korben.info/modern-web-guidance-agents-web.html
  • OpusBar (mondary.design, 12/11) — un chat pixel dans la barre des menus macOS qui surveille vos sessions Claude Code et Codex : alerte dès qu'un agent attend une permission, affiche les limites de votre offre, et ne sort rien de la machine. Gratuit : https://mondary.design/2026/11/opusbar/
  • Apple ouvre son framework « Foundation Models » (11-12/11) — Apple documente enfin l'accès aux modèles embarqués d'Apple Intelligence pour ses propres applications : pertinent si vous codez en Swift, mais aussi pour comprendre où va le calcul sur appareil côté macOS. Gratuit (compte développeur) : https://developer.apple.com/foundation-models-framework/
  • Visual Studio Code 1.145 (12/11) — les sessions d'agents distantes deviennent plus « locales » (aperçu d'application, canevas interactifs hébergés par l'hôte d'agents) et les automatisations d'agents locales se planifient en cron. Gratuit : https://visualstudio.developpez.com/actu/389012/Microsoft-publie-Visual-Studio-Code-1-145-avec-plusieurs-ameliorations-concernant-les-sessions-d-agents-IA-distants-et-des-planifications-cron-pour-les-automatisations-locales-des-taches-des-agents/
  • Journée des « modèles de décision » (12/11) — Google lance Gemini Decision 1 (jusqu'à 1 000 questions par appel, ~200 ms, 0,10 $ par million de jetons d'entrée, sortie gratuite, multimodal texte/image/audio/vidéo/PDF), quand Jev passe les 100 M$ de revenus récurrents : pour trier, noter ou classer, ces modèles non génératifs sont bien plus rapides et fiables qu'un LLM de raisonnement. https://simonwillison.net/2026/Nov/11/gemini-decisions-api/ et https://latent.space/p/ainews-d-day-decision-models-day
  • aws-emulator (Simon Willison, 11/11) — émulateur officiel d'AWS pour tester en local sans provisionner de clé payante ; écrit en Rust par un essaim d'agents (29 684 commits en trois semaines), il demande encore Docker sous macOS. Open source : https://github.com/aws/aws-emulator (récit : https://www.allthingsdistributed.com/2026/11/aws-emulator-and-the-engineers-job-when-agents-write-the-code.html)
  • Prompting Claude Fable 5.2 : dites à qui appartient le code (10/11) — une seule phrase, « ce code est le tien », fait passer la fusion du code dupliqué d'un dixième des essais à la moitié : la formulation a été relevée par Simon Willison dans la doc Anthropic, à réutiliser telle quelle dans ses gabarits. https://simonwillison.net/2026/Nov/10/prompting-claude-fable-52/
  • ai-explain : un « explique-moi comme si j'avais cinq ans » local (avonture.be, 12/11) — un script qui envoie le script ou le message d'erreur à un modèle local servi par Ollama et le reformule dans le terminal, sans qu'aucun fichier ne sorte de la machine. Gratuit, open source : https://www.avonture.be/blog/ollama-ai-explain

3. IA et éducation

  • « Protéger sans empêcher » : rapport de la Commission « IA générative et vulnérabilités » (via la DRNE, 12/11) — trois messages-clés : les risques de l'IA générative pour les plus jeunes sont de mieux en mieux documentés ; les vulnérabilités individuelles se répliquent à l'échelle des sociétés ; le modèle économique grand public n'est pas stabilisé. Utile pour argumenter un cadre d'usage en conseil pédagogique ou en CA. https://drne.region-academique-bourgogne-franche-comte.fr/proteger-sans-empecher-remise-du-rapport-de-la-commission-dexperts-novembre-2016/
  • Un concours de jeux vidéo étudiants supprimé après douze ans (developpez.com, 12/11) — l'Australian STEM Videogame Challenge ferme : les candidatures étaient submergées de productions médiocres générées par IA, impossibles à distinguer des jeux écrits sans IA. Cas d'école à garder pour les jurys, les concours et les évaluations de projets. https://jeux.developpez.com/actu/389011/Un-concours-de-developpement-de-jeux-video-pour-etudiants-supprime-apres-12-ans-les-jeunes-soumettant-sans-cesse-des-contenus-mediocres-generes-par-IA-trop-difficiles-a-distinguer-des-jeux-crees-sans-IA/
  • Comment Stanford enseigne l'ingénierie « IA-native » (Latent Space, 8/11) — quand l'agent sait faire le devoir de l'an dernier en une invite, le cours CS146S fait apprendre un dépôt inconnu, proposer un changement et défendre son correctif devant celui qui pourrait le fusionner : une transposition directe en NSI. https://latent.space/p/one_million_ai_engineer_special_how_stanford_teaches_ai-native_engineering_mihail_eric_monaco/
  • Traçabilité du code : distinguer l'élève de l'IA (arXiv 2611.09177, 9/11) — extension de l'approche « Min-K % » (génération de code synthétique + inférence d'appartenance) à du code Python, testée sur des rendus d'étudiants : les modèles gratuits laissent des traces plus détectables que les modèles commerciaux, et la détection s'accompagne d'un compromis avec la protection des données. https://arxiv.org/abs/2611.09177
