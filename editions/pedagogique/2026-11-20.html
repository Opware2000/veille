  • Mistral AI lance Vibe Desktop pour macOS et Windows (ActuIA, 19/11) — l'application de bureau de l'agent Vibe exécute plusieurs tâches en parallèle. Gratuit (version Pro payante). Une version Linux est annoncée. actuia.com

  • VS Code 1.147 : requêtes d'agent programmées et contrôle du navigateur (ActuIA, 18/11) — la fonction « Send Later » programme l'envoi d'une requête de chat ; « Browser Use » laisse les agents piloter Chrome ou Edge via Copilot. Gratuit, open source. code.visualstudio.com
  • Cloudflare publie Kitesurf, moteur de navigation pour agents IA (ActuIA, 17/11) — open source sous Apache 2.0. Fonctionne sans conteneur Chromium sur Cloudflare Workers : analyse le HTML, exécute le JavaScript et produit des captures d'écran. github.com/cloudflare/kitesurf
  • llama.cpp et ggml passent en 1.0 (ActuIA, 17/11) — les bibliothèques d'inférence locale de modèles de langage adoptent la gestion sémantique des versions. La version macOS native est disponible. Gratuit, open source. github.com/ggml-org/llama.cpp

  • Cloudflare publie les poids de Clairic, modèle d'extraction (ActuIA, 19/11) — 27 milliards de paramètres, extrait des champs structurés de textes, images et PDF. Servi sur Workers AI. Licence non précisée. huggingface.co/cloudflare
