IA pour le développement

Neuralink reçoit l'autorisation de la FDA pour son étude pivot LINK. Le 25 novembre, la Food and Drug Administration a approuvé le lancement de l'étude clinique sur humains du système implantable Neuralink, destinée en priorité aux personnes atteintes de sclérose latérale amyotrophique avec paralysie sévère. Le protocole porte sur la sécurité et l'efficacité du contrôle du curseur et de la saisie textuelle par interface cerveau-machine. Premier essai pivot de ce type aux États-Unis. Selon Interesting Engineering. https://www.actuia.com/veille/2026-11-26/#breve-6829

Google Workspace rend les serveurs MCP disponibles en GA. Gmail, Drive, Docs, Sheets, Slides, Calendar, Chat et Tasks embarquent chacun leur serveur MCP ; la CLI Workspace suit. Deux niveaux sont proposés : Standard, gratuit avec des limites publiées, et Scaled, facturé seulement au-delà des quotas quotidiens. Utilisation obligatoire de MCP pour les agents à partir du 1er février 2027. Des quotas gratuits distincts existent pour chaque application. https://www.actuia.com/veille/2026-11-26/#breve-6828

Baidu publie ERNIE 5.5 Flash Preview en open weights, Apache 2.0. Modèle à mélange d'experts de 280 milliards de paramètres total, 14 milliards actifs par token, contexte jusqu'à 1 048 576 tokens. Poids disponibles sur Hugging Face. Version Preview ouverte, version Base fermée reste propriétaire. https://www.actuia.com/veil.../2026-11-26/#breve-6818

Revolut remplace Claude Code par GLM auto-hébergé et divise sa facture par dix. David Abitbol, responsable infrastructure, explique lors d'une conférence que les 2 000 ingénieurs de la fintech ont basculé sur GLM-5.3 de Z.ai hébergé sur 56 Nvidia B200. Coût : 0,30 dollar/Mtoken au lieu de ~3 dollars pour Claude Code. Retour jugé décevant pour certains modèles commerciaux, mais gains significatifs sur les tâches récurrentes. https://korben.info/revolut-vire-claude-code-pour-une-ia-chinoise-et-divise-ses-couts-par-dix.html

Modern Web Guidance : apprendre aux agents IA les API natives du navigateur. Projet piloté par les équipes de Chrome, Edge, Firefox et MDN. Fournit à Claude Code, Codex et autres assistants un catalogue de fonctionnalités HTML/CSS/JS natives (dialog, Popover API, container queries, passkeys, CSP) pour remplacer les lignes de JavaScript qu'ils produisent systématiquement pour des opérations que le navigateur gère déjà. Open source. https://korben.info/modern-web-guidance-agents-web.html

Google DeepMind lance Mass Spec Skills pour Antigravity. Association de Gemini à des outils ouverts de spectrométrie de masse (matchms, SIRIUS, MAGMa, MetFrag, RDKit) et bases GNPS, MoNA, PubChem. Anthropic présente Claude Ship, trois agents pour la relecture de pull requests. PR Steward, en bêta, traite les contrôles CI/CD en échec. Un troisième agent finalise l'approbation. https://www.actuia.com/veille/2026-11-25/#breve-6743

OpenAI Daybreak : agents IA de test d'intrusion et génération automatique de correctifs. Daybreak Red Team attaque les applications web comme le ferait un pirate, isolé dans un périmètre dédié, afin de détecter les chemins d'attaque invisibles aux scanners classiques.
