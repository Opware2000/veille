4. Python pour l'enseignement

  • PEP 823 et 824 : les opérateurs ?. et ?? reviennent à l'ordre du jour pour Python 3.16. Après l'échec de la tentative précédente, les deux propositions sont de nouveau discutées ; sujet idéal pour faire comparer à des élèves plusieurs façons d'écrire un test de valeur nulle. https://realpython.com/python-news-november-2026/
  • Tachyon : un profileur par échantillonnage livré avec Python 3.15 (module profiling, PEP 799). Il s'attache de l'extérieur, ajoute très peu de surcoût, sait se brancher sur un processus déjà lancé et produit une flamme interactive avec --flamegraph. Parfait pour montrer en NSI où passe réellement le temps. https://realpython.com/python315-sampling-profiler/
  • PEP 798 : dépaquetage dans une compréhension. [*x for x in lists] aplatit une liste de listes sans boucle imbriquée ni itertools.chain(), et {**p for p in profiles} fusionne une liste de dictionnaires. Une ligne qui remplace trois. https://peps.python.org/pep-0798/
  • pytest 9.2 durcit parametrize : les cas mal formés sont désormais refusés au lieu de passer silencieusement — utile pour sécuriser des jeux de tests d'exercices notés automatiquement. https://realpython.com/python-news-november-2026/
  • PyScript passe en mode maintenance : le projet reste utilisable et corrigé, mais sans nouvelle évolution majeure. À savoir avant de bâtir un cours sur du Python dans le navigateur — JupyterLite et Basthon restent les options actives. https://realpython.com/python-news-november-2026/
