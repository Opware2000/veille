Veille r/opensource — vendredi 20 novembre 2026

En bref

Une journée riche en annonces de projets libres, portée par les découvertes de Hacker News et du collecteur opensourceprojects.dev. On retient BetterOffice, une suite bureautique en Rust prometteuse, Chipload pour l'usinage CNC, et la version 19 de PostgreSQL. Côté outils, le vérificateur Pyrefly promet de diviser par quinze le temps d'analyse des projets Python.

Applications et outils nouveaux

BetterOffice — Suite bureautique open source dont les moteurs OOXML sont écrits nativement en Rust. Se présente comme une alternative légère et rapide à LibreOffice pour la manipulation de documents Office sans dépendre de code C++ historique. Licence à vérifier, site betteroffice.dev.

Chipload — Logiciel de FAO 2.5D open source pour fraiseuses CNC. Importe DXF et SVG, propose le poches avec passes de finition, la découpe de profil, la gravure en V et en prism, le relief 3D par hauteur, le nesting et l'usinage en retournement. Développé par son auteur avec Claude, disponible sur github.com/chipload/chipload.

Pyrefly — Vérificateur de types pour Python écrit en Rust, annoncé comme quinze fois plus rapide que Mypy. Idéal pour les bases de code volumineuses où la vérification ralentit le cycle de développement. Dépôt : github.com/pyrefly-org/pyrefly.

AnyPS5 — Projet qui porte les exécutables PS5 vers Linux et Windows en les reliant à des bibliothèques natives plutôt qu'en les émuplant. Une approche qui évite la lourdeur des émulateurs traditionnels. Dépôt : github.com/boykopovar/anyps5.

Substrate — Bac à sable pour agents IA sur Kubernetes qui met en sommeil les agents inactifs au lieu de laisser les conteneurs consommer de la mémoire à vide. Destiné aux déploiements de flottes d'agents. Dépôt : github.com/agent-substrate/substrate.

Graphic Walker — Alternative open source à Tableau, livrée comme un composant React à intégrer dans une application. Permet l'exploration de données par glisser-déposer sans déployer une plateforme BI complète. Dépôt : github.com/kanaries/graphic-walker.

Freeplane — Application de mind mapping en Java (Swing, OSGi) avec support de formules et de calculs dans les nœuds. Fonctionne hors ligne, sans compte ni cloud. Dépôt : github.com/freeplane/freeplane.

Floccus — Extension navigateur (Firefox, Chrome) qui synchronise les favoris via Nextcloud, Git ou WebDAV, sans passer par le cloud d'un éditeur. Dépôt : github.com/floccusaddon/floccus.

Flowgram AI — Framework de workflows visuels développé par ByteDance, avec canvas glissable, formulaires de nœuds et portée de variables. Destiné à la construction d'applications agents. Dépôt : github.com/bytedance/flowgram.ai.

Tiviate — Lecteur IPTV GPL-3.0 pour Android TV, Fire TV et téléphones, écrit en Kotlin avec Jetpack Compose et Media3. Chaque fonctionnalité est gratuite et le code est ouvert. Présenté par son développeur sur Reddit.

nyaa.si TUI — Interface en mode texte (Rust, ratatui) pour parcourir les torrents d'anime de nyaa.si depuis le terminal. Pas de scraping, alimenté par le flux RSS. Dépôt : github.com/metaory/nyaa-tui.

MdNotePad — Éditeur Markdown gratuit pour Windows 10/11, d'aspect minimal (comme le Bloc-notes) mais avec rendu en direct des titres, listes, code et liens. Supporte les tableaux en grille et les diagrammes Mermaid intégrés.

SoduWork — Workbench open source (MIT) où les agents IA doivent prouver leur travail avant qu'il soit accepté. Déjà 4 181 étoiles sur GitHub, dernière mise à jour le 19 novembre 2026. Dépôt : github.com/mdiri-ai/SoduWork.

HyCanvas — Alternative à Canva écrite en Go, sous licence AGPL-3.0 (306 étoiles, mise à jour le 19 novembre 2026). Dépôt : github.com/hyscaler/HyCanvas.

Lattice — Alternative open source à Obsidian Publish, pour publier des notes Markdown en ligne sans abonnement. Présenté sur lattice.jacobg.co.

CopySpeech — Application de synthèse vocale open source qui lit à voix haute tout texte copié dans le presse-papiers. Dépôt : github.com/ilyaizen/CopySpeech.

Motion Wallpaper — Fond d'écran animé libre et ultra-léger pour Linux (X11 pour l'instant). Dépôt : github.com/sozipp/motion-wallpaper.

Pritunl Client — Client OpenVPN et WireGuard gratuit, open source et multiplateforme. 1 481 étoiles, mis à jour le 18 novembre 2026. Dépôt : github.com/pritunl/pritunl-client.

ExtendDB 1.0 — Adaptateur open source compatible DynamoDB publié par AWS. Permet d'utiliser des bases DynamoDB-compatibles sans verrouillage propriétaire.

Onlook — Application de bureau open source qui superpose une interface de conception graphique sur une base de code réelle. Déjà 25 000 utilisateurs, a été deux fois numéro 1 des tendances GitHub. Dépôt : github.com/onlook-dev/onlook.

pie-tui — Harness TUI et CLI open source pour développeurs Android : création de pull requests, correction automatique des commentaires de revue, le tout depuis le terminal. Dépôt : github.com/Apple-Pie-AI/pie-tui.

minUS — Plateforme de développement d'échographie open source minimale basée sur un PIC32, pour l'apprentissage et le prototypage. Présenté sur kelu124.github.io/minus.

SHARD — Projet d'inférence distribuée open source. Cherche des contributeurs pour son développement. Dépôt : github.com/avelone123123/shard.

Panda Federation Tools — Serveur MCP open source (MIT) pour outils de recherche et données publiques pay-per-result. Tout nouveau (0 étoiles, 19 novembre 2026). Dépôt : github.com/pandadad0214/panda-federation-tools.

The Adversary — Firmware open source pour ESP32 destiné aux tests d'intrusion des réseaux sans fil. Dépôt : github.com/Isonimus/adversary.

Raven Recon — Framework de recherche en sécurité open source utilisant des agents IA. Dépôt : github.com/9illcodelli6-cpp69cve/raven-recon.

XApp — Ensemble d'applications et de bibliothèques conçues pour fonctionner sur tous les environnements de bureau Linux (GNOME, KDE, Xfce, etc.). Projet initié par le développeur du bureau Cinnamon. Site : xapp-project.org.

sysdeck — Lanceur d'applications et de commandes pour Linux et BSD, comparable à Raycast sous macOS. Présenté par son auteur.

I Did My Own — Annuaire de projets open source où quelqu'un a reconstruit une application célèbre (alternative to X). Site : idmo.app/own.

Nouveautés et mises à jour

PostgreSQL 19 — Nouvelle version majeure du SGBD open source, avec des améliorations de performances. La publication a été retardée de plusieurs semaines à cause de l'afflux de rapports de bogues générés par l'IA. Vu sur Phoronix.

PHP 8.6 — Nouvelle version majeure du langage, avec la fonctionnalité Partial Function Application et d'autres améliorations. Également des correctifs de sécurité pour les branches 8.2 à 8.5. Vu sur Phoronix et Lobsters.

Valkey 9.2 — Dernière version du fork ouvert de Redis, avec compression Zstd, réduction de l'empreinte mémoire et gains de performances. Vu sur Phoronix.

AMD ROCm 10.2 — Nouvelle version de la pile de calcul GPU open source d'AMD, avec optimisations et support étendu des laptops Ryzen. Mise à jour à six semaines. Vu sur Phoronix.

GNOME 51 — Nouvelle version majeure de l'environnement de bureau, avec son lot de nouveautés. Vu sur Lobsters.

jQuery 4.1.0 et 3.8.0 — Les deux versions de la bibliothèque JavaScript corrigent une vulnérabilité ReDoS. La version 4.1.0 est la première mineure de la série 4.x. Vu sur Developpez.com et Lobsters.

Unsloth Desktop — Le client de bureau supporte désormais l'inférence locale sur les NPU AMD Ryzen AI (XDNA 2), y compris sous Linux. Vu sur Phoronix.

Haiku — Automne 2026 — Le système d'exploitation open source a publié sa R1 bêta 6. Le rapport d'activité couvre les mois d'août à octobre (plus de 300 changements dans le code source). Vu sur LinuxFr.org.

LiberNT — Fork de ReactOS utilisant l'IA pour accélérer le développement, avec pour objectif la compatibilité Windows 11. Une approche controversée dans la communauté. Vu sur Phoronix.
