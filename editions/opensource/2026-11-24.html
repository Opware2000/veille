Veille r/opensource — mardi 24 novembre 2026

En bref

PostgreSQL 19 sort en version stable avec une refonte de la gestion des tables. LibreOffice 27.2 Alpha 1 est disponible pour tests. Rust 1.100 et FFmpeg 9.1 complètent le carnet de releases du jour. Plusieurs nouveaux outils libres méritent l'attention, notamment OpenShorts (nearly 10k étoiles) et un dashboard Linux complet.

Applications et outils nouveaux

OpenShorts — générateur de shorts vidéo à partir de longs formats vidéo, alimenté par l'IA mais open source. Permet d'extraire automatiquement des segments courts de vidéos existantes. Python, licence MIT, ~9 800 étoiles sur GitHub (source: mutonby/openshorts).

Budget — application de suivi budgétaire personnelle pour Mac et Windows, mode simple pour les budgets et dépenses courants, mode avancé avec report des reliquats et répartition multi-budgets. Données stockées localement via Markdown dans Git. GPL-3.0, langage Python, 1 étoile (hendrikdemir/budget). Gratuit.

Hermit CRM — CRM open source pour solopreneurs et indépendants. Conçu pour suivre les prospects et deals au sein d'une petite structure : données stockées en Markdown dans Git, accessible via application web. Licence GPL-3.0, Python, 1 étoile (gijsbos/hermit-crm). Gratuit.

Just Dashboard — panneau de contrôle privé pour serveur Linux : déploiement d'applications, Docker, bases de données, proxy et TLS, terminal intégré, gestion de fichiers, Git et sauvegardes. Go, licence AGPL-3.0, 26 étoiles, dernière mise à jour le 23/11 (JustDashboard/Just-Dashboard). Gratuit et auto-hébergeable.

Dawarich — solution de géolocalisation auto-hébergée. Trace les déplacements et permet un partage familial du positionnement, sans dépendance aux services propriétaires. Source non spécifiée (dawarich). Gratuit.

Satura — espace de travail Apache 2.0 pour agents IA qui « vous tendent la main » pendant la programmation. Interface de travail collaborative pilotée par IA (satura.space).

Pentworks — outil CLI open source pour gérer des projets de tests d'intrusion (penetration testing). Organisation des engagements, traçabilité et rapports. Python, aucune licence identifiée, 8 étoiles (Sheykder/Pentworks). Gratuit.

ScreenTinker — logiciel de signalétique numérique distante open source pour vos propres téléviseurs. Serveur + clients légers. JavaScript, licence MIT, 277 étoiles, 76 forks, dernière MAJ le 23/11 (screentinker/screentinker). Gratuit.

Tellyscope — lecteur/streamer TV internet Kotlin, licence GPL-3.0, 2 217 étoiles (man15h/tellyscope). Gratuit.

Inbox Envoy — compétence open source de tri d'emails dédiée à votre propre agent IA. Filtre, classifie et priorise les messages entrants. Python, licence MIT, 4 étoiles (salespeak-ai/inbox-envoy). Gratuit.

Nouveautés et mises à jour

PostgreSQL 19 — sortie officielle de cette version majeure de la base de données relationnelle open source. Gestion des tables entièrement repensée, performances accrues et nouvelles fonctionnalités (source: phoronix, developpez). PostgreSQL sous licence PostgreSQL (permissive).

LibreOffice 27.2 Alpha 1 — première version alpha destinée aux tests, en vue de la sortie stable prévue en février. La suite bureautique libre poursuit son cycle de développement bi-mensuel (source: phoronix). MPL-2.0.

Rust 1.100 — ce release stabilise le type never, l'API Allocator et implémente l'API DropGuard. Ce sont des évolutions fondamentales du language (source: developpez).

FFmpeg 9.1 — nouvelle version de la référence open source pour le traitement audio/vidéo. Changelog détaillé disponible (source: phoronix).

Wine 11.22 — nouvelle publication du compatibilité Windows/Linux, incluant des correctifs OpenGL et des améliorations cross-process render (source: phoronix).

KDE Plasma 6.9 — la maquette XWayland on demand est désormais intégrée, permettant de basculer selon besoin entre Wayland et X11 par session (source: phoronix).

Mesa 26.3.1 — correction de régressions et bugs dans les pilotes GPU Mesa (source: phoronix).

Blender 5.3 — nouvelle version majeure de la suite 3D open source. Mises à jour notables (source: phoronix). LGPL-2.1.

Linux 7.4-rc4 — quatrième candidate release du noyau Linux 7.4, marqué comme volumineux par Linus Torvalds. Inclut de nombreuses corrections et nouveautés (source: phoronix).

Linux 7.4-rc3 — release candidate précédente marquant aussi des progrès significatifs (source: phoronix).

Firefox 161 — navigation web open source ajoutant le basculement VPN par site et une section de thèmes classiques. Le VPN intégré gratuit avec volume illimité fonctionne jusqu'en janvier 2027 (source: phoronix). Mozilla Public License.

PHP 8.6 — nouveau release du langage incluant l'application partielle de fonctions, une nouvelle classe Duration et une API de polling. (source: phoronix, developpez).

NVIDIA 620.73.04 — pilote Linux NVIDIA, mise à jour mensuelle de drivers GPU (source: phoronix).

Fedora 46 approuve RPM v6 — la prochaine Fedora adoptera le format RPM v6 dans son infrastructure de paquets (source: phoronix).

openSUSE Leap 16.1 → Agama — la distribution openSUSE Leap migre vers l'installateur Agama (source: phoronix).

Shirudo — runtime open source développé conjointement par OpenAI et Cisco pour protéger les systèmes Linux non patchés. Exécution en environnement isolé pour limiter l'exposition aux vulnérabilités connues (source: OpenAI blog).

Arti 2.8 — nouvelle version du client Tor de nouvelle génération écrit en Rust, se rapprochant d'une réécriture complète (source: developpez).
