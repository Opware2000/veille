Veille r/opensource — samedi 28 novembre 2026

En bref

Linux Mint 27 passe en bêta avec un support Wayland intégral et Pop!_OS 26.04 LTS est officiellement disponible. systemd 263 intègre ses premières lignes de code en Rust. Parmi les nouveaux projets sélectionnés : un éditeur vidéo complet, un accès natif à iCloud sur tous les systèmes, et un outil permettant à un agent IA d'interagir avec un téléphone réel.

Applications et outils nouveaux

Concat — éditeur vidéo open source autonome
Un éditeur vidéo qui propose souscription gratuite : sous-titrage automatique, isolation vocale, keyframes et montage non-linéaire. Alternative libre aux éditeurs par abonnement. Licence AGPL-3.0. 22 000 étoiles sur GitHub. https://github.com/jub0t/concat

SkyKeep — applications iCloud pour Windows, Linux et Android
Accédez à vos notes, calendrier et autres données iCloud depuis n'importe quel système sans passer par le navigateur web. Écrit en Rust. GPL-3.0. 900 étoiles. https://github.com/yashwanthkamireddi/skykeep

Phone Harness — contrôlez un téléphone réel depuis un agent IA
Permettez à Claude Code ou tout autre agent d'interagir avec un vrai téléphone (touchers, saisies, lectures d'écran). Ferme la brèche entre l'automatisation logicielle et les appareils physiques. Licence MIT. 6 000 étoiles. https://github.com/phone-harness/phone-harness

OpenGame — transformez votre agent de codage local en studio de jeu complet
Fournit à Claude Code, Codex ou tout agent comparable les outils nécessaires pour construire un jeu 3D jouable de bout en bout, avec rendu, logique et design intégrés. Apache-2.0. 2 200 étoiles. https://github.com/nexu-io/opengame

SoundEtch — éditeur de podcasts et médias dans le navigateur
Éditeur audio open source fonctionnant entièrement dans le navigateur desktop, sans installation ni compte. Prend en charge podcast et média. https://soundetch.org

OxiCloud — serveur de fichiers, calendrier et contacts en Rust
Serveur self-hosted proposant gestion de documents, synchronisation de calendrier et répertoire téléphonique, conçu avec Rust pour la sécurité et les performances. https://www.fredix.xyz/2026/11/oxicloud/

TorqWave — éditeur audio spectral et MAO
Éditeur audio C++20/JUCE orienté analyse spectrale avec licence AGPL-3.0. Récent, mais pertinent pour l'audio professionnel. https://github.com/BobClawblaw/torqwave

Lelvo — sauvegarde photo chiffrée de bout en bout, sans serveurs
Application open source de sauvegarde photo chiffrée ne reposant sur aucun serveur centralisé. Les données restent uniquement chez l'utilisateur. License GPL-3.0. https://github.com/shahil-kv/Lelvo

Flipper Zero — kit CAN bus pour Tesla
Toolkit open source pour explorer et interagir avec le bus CAN des véhicules Tesla à partir d'un Flipper Zero (matériel dès 14 $). https://github.com/hypery11/flipper-tesla-fsd

Audio-SWARM — application de bureau Python pour formes d'onde audio
Génère des images de forme d'onde propres à intégrer comme couvertures d'album, avec traitement par lots de dossiers, spectres circulaires/radiaux et intégration en masse. Licence AGPL-3.0. Auteur original s'exprimant ici même sur Reddit.

Nouveautés et mises à jour

Linux Mint 27 — version bêta
Bêta annoncée avant la version officielle prévue pour les fêtes. Apporte un support Wayland plein (et non plus optionnel), ainsi que de nouvelles applications incluses. https://www.phoronix.com/news/Linux-Mint-27-Beta

Pop!_OS 26.04 LTS
Version longue durée disponible, sortie de System76. https://system76.com/blog/post/pop_os-26-04-lts-has-landed

systemd 263-rc1
Premier gel candidat pour la prochaine grande version. Introduit un support initial du langage Rust pour créer de nouveaux programmes, un service de courtier pseudo-TTY expérimental, un outil de manifeste et un nouveau service keyring. https://www.phoronix.com/news/systemd-263-rc1

Pilote Vulkan Intel — mode e64 activé par défaut
Le pilote ANV pour Linux active maintenant en mode par défaut l'adressage mémoire 64 bits efficace (« e64 »), remplaçant le mode décalage 32 bits utilisé jusqu'alors. Débutera avec les processeurs Intel Nova Lake P à graphique Xe3P intégré. https://www.phoronix.com/news/Intel-Efficient-64-bit-e64-ANV

ZenSMU — suivi et overclocking AMD Ryzen
Utilitaire open source fournissant une interface CLI/TUI et une véritable interface graphique Linux pour surveiller et ajuster les paramètres du processeur AMD Ryzen, en absence d'utilitaire officiel AMD. https://www.phoronix.com/news/ZenSMU-Linux-TUI-GUI

runtime Compute Intel 26.44.40734.8
Nouvelle mise à jour du runtime GPU open-source pour Linux et Windows, apportant des améliorations de performance. https://www.phoronix.com/news/Intel-Compute-26.44.40734.8

Support RDNA 5 dans le noyau Linux 7.5
Le pilote graphique initial pour la nouvelle puce GFC13 / GC 13 d'AMD (RDNA 5) devrait atterrir dans Linux 7.5. https://www.phoronix.com/news/AMD-RDNA5-Linux-7.5

Omarchy 4.6 RC1
Distribution Arch Linux centrée sur l'IA, avec davantage d'intégrations locales IA et son propre gestionnaire de fichiers. https://www.phoronix.com/news/Omarchy-4.6-Released

Quoth — reconnaissance vocale locale IA pour Linux
Outil de speech-to-text local qui choisit votre matériel plutôt que de vous imposer un modèle prédéfini. Mentionné sur itsFOSS. https://feed.itsfoss.com/link/24361/17516378/passbolt-review

Extensions et greffons

Node Modules Inspector — visualisez node_modules
Visualisez les dépendances de vos projets Node.js, inspectez les paquets dupliqués et évaluez les tailles d'installation. Licence MIT, ~3 000 étoiles. https://github.com/antfu/node-modules-inspector

DiscordChatExporter — export d'historique de discussion Discord
Application open source pour exporter l'historique complet d'un serveur ou canal Discord vers un fichier. Une manière simple de récupérer les conversations sans passer par les API propriétaires. https://github.com/tyrrrz/discordchatexporter

ComfyUI — moteur de graphes de nœuds pour modèles de diffusion
Moteur d'inférence open source basé sur un graphe de nœuds, capable d'exécuter les derniers modèles de diffusion sur 4 Go de VRAM. Déjà bien établi (près de 149 000 étoiles), présenté ici comme projet notable de la sélection quotidienne opensourceprojects.dev. https://github.com/comfy-org/comfyui
