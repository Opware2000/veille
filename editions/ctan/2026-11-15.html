En bref

  • Un nouveau paquet mérite votre attention : beamer2html, qui transforme une présentation beamer en diaporama HTML autonome à partir des mêmes sources que le PDF.

Mises à jour des paquets que vous utilisez

mathtools 1.32 (version du 12 novembre 2026, annonce du 14) — licence LPPL 1.3c, maintenu par l'équipe du projet LaTeX. La version précédente datait d'octobre 2024. Trois corrections annoncées :

  • l'option centercolon fonctionne de nouveau correctement en régime unicode-math — c'est la correction qui vous concerne directement, puisque nBook3 charge unicode-math ; si vous employez \coloneqq ou l'option centercolon dans vos cours, le double-point est désormais centré comme il doit l'être. Mettez votre distribution à jour avant de juger un rendu bizarre : c'est le rendu ancien qui était fautif, pas vos sources ;
  • les environnements cases étoilés (dcases*, rcases*…) ignorent à nouveau les espaces avant la fin de l'environnement, ce qui supprime un blanc parasite en fin de ligne ;
  • correction d'un espace supplémentaire introduit lorsque l'environnement contient un environnement de type align.

Aucune adaptation de votre classe n'est nécessaire : mathtools conserve son interface et il est improbable que vos documents dépendent des espacements fautifs. La page du paquet contient le détail : https://ctan.org/pkg/mathtools

Nouveaux paquets pertinents

beamer2html 1.0 (première version, licence triple LPPL 1.3c / Apache 2 / GFDL) — https://ctan.org/pkg/beamer2html

Le paquet a deux parties : beamer2html.sty, une extension pour vos sources beamer (pages de titre, barre de titre et pied de page, disposition en lignes et colonnes, tableaux, frise de progression, listes de publications et de bibliographie, formes posées sur les figures, vidéos, tracés pgfplots, animations à partir de séquences d'images, styles d'organigrammes TikZ), et beamer2html, un programme Python 3 qui écrit slides.html à partir de ces mêmes sources. Le diaporama HTML obtenu est autonome et fonctionne hors ligne dans un navigateur : les recouvrements (\pause, <2->, \only, \uncover) se comportent comme dans beamer, les tracés pgfplots deviennent interactifs (valeurs sous le curseur, zoom, masquage de courbes), les TikZ sont compilés par LaTeX pour rester identiques au PDF, et une vue présentateur affiche les notes, la diapositive suivante et un chronomètre. L'option --pack produit une archive zip contenant exactement les fichiers utilisés, avec conversion facultative des images en WebP ; --watch reconstruit à chaque enregistrement.

L'intérêt est double pour vous : vos diapositives restent écrites en beamer — donc compatibles avec nBookSlides — mais vos élèves peuvent les ouvrir dans un navigateur, sans lecteur PDF, avec des animations et des tracés manipulables. Le vrai PDF continue d'être produit par les mêmes sources. Le programme Python 3 est une dépendance à installer sur votre poste, ce que je n'ai pas vérifié ici ; je n'ai pas non plus testé la conversion sur une présentation existante.

Autres mises à jour notables

  • colorframed 1.0 et hawkdraw 0.11.2 : deux corrections du même ordre, la compatibilité avec le PDF étiqueté — colorframed (cadres colorés du paquet framed) devient utilisable sous \DocumentMetadata, et hawkdraw (dessin vectoriel sur l3draw) corrige la boîte englobante des groupes étiquetés. Vos documents n'emploient pas \DocumentMetadata, leur sortie est donc inchangée ; c'est à noter si vous activez un jour tagging=on.
