Applications et outils nouveaux

PorterApp — visualiseur et gestionnaire de ports réseau

Application de bureau libre qui affiche tous les ports ouverts sur votre machine, identifie le processus utilisateur pour chacun, et permet d'interrompre un port d'un clic. Développée en Rust avec Tauri, elle fonctionne sur Mac, Windows et Linux.

Licence : MIT. Prix : gratuit.

Source : r/BestGitHubRepos · Dépôt : github.com/t21dev/porter-app (184 étoiles, dernière mise à jour 23/11/2026).

Ladybird — navigateur web open source basé sur un moteur indépendant

Le projet SerenityOS présente la première version téléchargeable en alpha de Ladybird, son navigateur web. Contrairement à presque tous les navigateurs modernes, Ladybird n'utilise ni Blink (Chromium) ni Gecko (Firefox), mais un moteur écrit entièrement en C++ utilisant sa propre boîte à widgets. Les premiers tests montrent que le rendu est déjà « étonnamment capable » selon Ars Technica. Le projet existe depuis plusieurs années au sein du dépôt principal SerenityOS (34 000 étoiles au total).

Licence : BSD-2-Clause. Prix : gratuit.

Sources : The Register · Ars Technica · Dépôt : github.com/SerenityOS/serenity.

Rvoip — pile VoIP open source en Rust

Stack complète SIP/VoIP implémentée en Rust : traitement SIP, WebRTC, SRTP et agents vocaux IA derrière une seule API. L'implémentation a été benchmarkée selon la RFC 7502 et est documentée par ses créateurs. Solution intéressante pour quiconque doit intégrer ou étendre des fonctions téléphoniques dans une architecture logicielle.

Licence : MIT. Prix : gratuit.

Source : Hacker News · Dépôt : github.com/eisenzopf/rvoip (523 étoiles, dernière mise à jour 27/11/2026).

Natively — assistant de réunions et retranscription

Alternative open source aux assistants de réunions payants (Cluely, Otter, Fireflies). Fonctionnalités : retranscription en temps réel, notes générées par IA, enregistrement de conférences, RAG local, mode furtif. S'exécute localement, sans abonnement ni partage de données. Développé par un indépendant.

Licence : licence non précisée dans le dépôt. Prix : gratuit.

Source : gitmanual — trending (3 403 étoiles, dernière mise à jour 27/11/2026).

Pulse — tableau de bord de supervision infrastructure

Dashboard de surveillance en temps réel pour Proxmox VE, PBS, Docker, Kubernetes, TrueNAS et vSphere. Auto-hébergé, avec alertes pour sauvegardes échouées, disques pleins, conteneurs malsains et nœuds hors ligne. Interface claire pour piloter plusieurs environnements virtualisés depuis un même lieu.

Licence : MIT. Prix : gratuit.

Source : gitmanual — trending (7 219 étoiles, dernière mise à jour 27/11/2026).

Nouveautés et mises à jour

DietPi — version 10.9

La distribution légère DietPi (dédiée aux ordinateurs monocartes et serveurs) publie la version 10.9. Distribution Debian minimaliste équipée de dialogs console pour installer des piles logicielles complètes. Version GPLv2. 6 457 étoiles.

Source : Hacker News · Dépôt : github.com/MichaIng/DietPi.
