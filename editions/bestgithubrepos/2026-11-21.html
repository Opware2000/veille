Veille r/BestGitHubRepos — samedi 21 novembre 2026

En bref

Une journée chargée en découvertes : plusieurs projets d'agents autonomes open source (Nod, Suparagent, CUA), un moteur d'inférence hiérarchique pour modèles MoE qui tourne sur le matériel existant, un outil de vérification de code local avec les règles OWASP et un gestionnaire de dépôts Hugging Face auto-hébergé. Côté petits utilitaires, un moniteur de batterie pour périphériques sans fil sous Windows, un launcher macOS pour outils jetables et un client YouTube alternatif.

Applications et outils nouveaux

Nod — Agent personnel open source qui chasse les factures, prépare les appels et annule les abonnements sur de vrais sites web. Il tourne sur votre machine avec le modèle de votre choix et demande avant d'agir. Développé par n8n. Licence Apache 2.0, gratuit. Dépôt : github.com/n8n-io/nod (2 837 étoiles, mis à jour le 20 novembre).

Suparagent — Alternative open source et auto-hébergeable à Grok Bot, Claude Duet, OpenAI Dots et Meta Muse. Des « collègues IA » (agents nommés) avec instructions, mémoire, routines, leur propre machine isolée et votre approbation avant d'agir. Licence Apache 2.0, gratuit. Dépôt : github.com/Anil-matcha/suparagent (7 130 étoiles).

CUA (Computer Use Agents) — Pilotes open source pour l'utilisation d'ordinateurs (computer-use 2.0), sandbox multi-systèmes et benchmarks pour l'entraînement et l'évaluation. Idéal pour quiconque veut construire ou évaluer des agents qui manipulent une interface graphique. Licence MIT. Dépôt : github.com/trycua/cua (32 716 étoiles).

Colibri — Moteur d'inférence hiérarchique pour modèles MoE (Mixture of Experts) frontières. Les experts « chauds » sur GPU (CUDA/Vulkan), les « tièdes » en RAM, les « froids » diffusés depuis le NVMe. Écrit en C, utilise le matériel que vous possédez déjà. Licence Apache 2.0. Dépôt : github.com/JustVugg/colibri (52 471 étoiles).

Paperclip — Application open source pour gérer les agents en environnement professionnel. Interface unifiée pour superviser, configurer et orchestrer plusieurs agents IA. Licence MIT. Dépôt : github.com/paperclipai/paperclip (115 481 étoiles).

Datacat (Replit) — Plateforme d'observabilité auto-hébergée : métriques, logs, traces, tableaux de bord et alertes. Stocke les données dans PostgreSQL ou ClickHouse et accepte les données OpenTelemetry. Licence Apache 2.0. Dépôt : github.com/replit/datacat (463 étoiles).

Invidious — Interface alternative à YouTube, légère et respectueuse de la vie privée. Permet de regarder des vidéos sans tracking, sans compte Google et avec moins de ressources. Licence AGPL 3.0. Dépôt : github.com/iv-org/invidious (26 107 étoiles).

Wireless Device Battery Monitor — Affiche le niveau de batterie des souris, casques, claviers et manettes sans fil dans la barre des tâches Windows 10/11. Application légère, ne nécessite pas les logiciels propriétaires des constructeurs. Supporte Logitech, Razer, SteelSeries, Corsair, HyperX, Glorious, manettes PS4/PS5 DualSense, Xbox et Bluetooth. Licence GPL 3.0. Dépôt : github.com/krisgfx9/Wireless-Device-Battery-Monitor (5 278 étoiles).

Openspot — Lanceur macOS pour outils « jetables » : l'agent de codage génère un outil (spot) pour la tâche en cours, vous le gardez si utile ou le supprimez après usage. Projet de recherche open source utilisant l'UI générative. Licence MIT. Dépôt : github.com/celishq/openspot (5 étoiles).

Vestige — Moteur de mémoire déterministe pour agents, écrit en Rust, sans LLM. Stocke et retrouve des informations de façon prévisible sans recourir à un modèle de langage. Licence AGPL 3.0. Dépôt : github.com/samvallad33/vestige (662 étoiles).

Chipload — Logiciel de FAO (CAM) 2,5D open source pour fraiseuses CNC. Import DXF/SVG ou dessin intégré, poches avec passes de finition, profil avec languettes, gravure en V, prismes, moulures et 3D relief. Génération de G-code. Licence GPL 3.0. Dépôt : github.com/chipload/chipload (18 étoiles).

Dayfile — Journal à ajout seul (append-only) pour scripts et agents, comparable à un « git log » pour l'automatisation. Enregistre les tâches, les succès et échecs d'exécution dans un historique ordonné. Actuellement en bêta. Licence AGPL 3.0. Dépôt : github.com/dayfile/dayfile (0 étoile, tout juste lancé).

Lintsure — Vérification de code locale et gratuite avec les règles OWASP, EU AI Act et autres standards de conformité. OSS, fonctionne hors ligne. Licence Apache 2.0. Dépôt : github.com/lintsure/lintsure (3 étoiles).

FluentFlyout — Fenêtres contextuelles modernes pour Windows 11, conçues selon les principes Fluent 2 : contrôles multimédia, widgets de la barre des tâches, etc. Licence GPL 3.0. Dépôt : github.com/unchihugo/FluentFlyout (4 945 étoiles).

PocketBase — Backend open source temps réel en un seul fichier. Idéal pour prototyper une application avec base de données, authentification et API sans infrastructure. Une seule binaire à déployer.

Self-hosted Hugging Face model registry — Registre OSS auto-hébergé pour modèles et ensembles de données Hugging Face. Permet de conserver ses modèles en local sans dépendre du cloud. Licence Apache 2.0. Dépôt : github.com/model-delivery/registry (5 étoiles).

Citeparse — Analyse les listes de références bibliographiques et détecte les citations inventées, le tout sur CPU. Utile pour vérifier la bibliographie d'un article. Licence Apache 2.0. Dépôt : github.com/un-seen/citeparse (1 étoile).

gh-sift — Extension pour GitHub CLI qui affiche PRs, diffs, logs d'actions et PRs empilés dans une interface TUI. Remplacement direct de gh-dash avec prise en charge des merge queues et des révisions de diff intégrées. Licence MIT. Dépôt : github.com/chrismatix/gh-sift (0 étoile, tout juste publié).

Brisk — Éditeur de texte léger inspiré de PyCharm, écrit en Rust. Expérimental. Licence Apache 2.0. Dépôt : github.com/thirisnospoon/brisk (1 étoile).

LZ0 — Compresseur LZ asymétrique avec décodeur ultra-minimal (zéro allocation). Idéal pour les systèmes contraints. Licence MIT. Dépôt : github.com/seb3773/lz0 (0 étoile).

FdroidManager — API et interface web pour gérer un dépôt F-Droid privé. Permet de distribuer ses propres APK Android à sa famille sans passer par le Play Store. Licence MIT. Dépôt : github.com/npodbielski/FdroidManager (0 étoile).

Cypher MCP — Couche MCP locale sur SQLite qui expose Cypher pour qu'un LLM puisse interroger et modifier un graphe de connaissances. Utile pour donner une mémoire structurée à vos agents. Licence MIT. Dépôt : github.com/vmikhailov/cypher-mcp (2 étoiles).

ErXos — Microkernel OS expérimental écrit en Erlang, inspiré de Genera/Plan 9/QNX. Chaque processus Erlang est un processus système ; les pilotes, systèmes de fichiers et la pile réseau sont des processus Erlang supervisés. Licence BSD 2-Clauses. Dépôt : github.com/stass/erXos (6 étoiles).

Forbear — Bibliothèque d'UI en mode immédiat qui ressemble au web, avec une DX à la React, écrite en C. Une calculatrice tient dans 3,6 Mo de binaire et 10,5 Mo de RAM. Dépôt : github.com/gabrielmfern/forbear (59 étoiles).

Extensions et greffons

Eachlabs Skills — Ensemble de compétences (skills) pour agents de codage IA : génération d'images, vidéos, musique, voix off et plus, directement depuis le terminal. Dépôt : github.com/eachlabs/skills.

Impeccable — Vocabulaire de design pour agents de codage : orienter avec « polish » et « bolder », réviser avec « critique » et « audit », détecter le « slop » IA avant publication. Dépôt : github.com/pbakaus/impeccable.

InteraOne — Alternative open source à Intercom et Zendesk, avec agents IA intégrés. Gratuit et auto-hébergeable. Vu sur Product Hunt.
