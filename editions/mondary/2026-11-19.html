Documents, notes et bureautique

WRITER — un éditeur Markdown local qui démarre instantanément (writer.computer). Application de bureau qui ouvre directement un dossier de fichiers .md : pas de bibliothèque cachée, pas de synchronisation, pas de compte. Elle respecte le .gitignore du dossier ouvert, gère plusieurs fenêtres et onglets (un dossier de documentation d'un côté, des notes personnelles de l'autre), une palette de commandes Cmd+P qui retrouve un fichier sans quitter le clavier, et le rendu des tableaux, des diagrammes Mermaid, du HTML et du frontmatter YAML. La ligne de commande est prise en charge : writer . ouvre le dossier courant. Le démarrage à froid tient en une fraction de seconde, et la télémétrie est désactivée par défaut. Système : macOS uniquement, pour l'instant, et seulement Apple Silicon. Licence : GPL-3.0, code ouvert, mais la version publique est encore en bêta (téléchargements signés et notariés en cours). C'est l'outil qui correspond le mieux à votre façon de travailler : vous rédigez déjà vos cours en Markdown dans des fichiers ; Writer évite d'attendre le lancement d'une application web pour corriger deux lignes. Limite à connaître : macOS seulement, donc il ne remplace pas votre poste s'il n'est pas sous macOS.

JAM — enregistrer un bug avec tout son contexte technique (jam.dev/mac). Extension et application de capture d'écran et d'enregistrement vidéo, orientée signalement de problème : au lieu de rédiger un ticket, on enregistre l'écran et l'outil joint automatiquement les journaux de la console, les requêtes réseau, les interactions et les informations sur la machine, puis génère un titre, une description et les étapes de reproduction. Partage vers Jira, Linear ou Slack, et lien de signalement pour un utilisateur extérieur sans installation. Un serveur MCP et une CLI sont fournis, donc un agent peut analyser le bug et documenter la correction. Système : macOS, extension Chrome pour les navigateurs Chromium, extension propre à Safari livrée avec la version Mac, et une application iOS. Trois limites à retenir, données par l'auteur : une capture de zone ne joint aucun journal, une capture plein écran ignore les applications Electron, et une application Electron doit être relancée une fois par session pour que ses journaux soient captés. Prix : le billet ne donne ni le tarif ni le détail des limites de la version gratuite ; l'auteur l'annonce lui-même comme un point à vérifier, je ne peux donc pas trancher sur ce point.

Intelligence artificielle, agents et modèles locaux

EKKO STUDIO — un atelier local pour réunir tous ses agents IA (ekkostudio.xyz). Espace de travail local-first qui réunit dans une seule interface le chat multi-agents, les agents de code et des workflows visuels, là où l'on empile habituellement un terminal pour Claude Code, un autre pour Codex, une fenêtre pour OpenCode et un onglet pour un modèle local. Quatorze intégrations d'agents de code sont annoncées (Claude Code, Codex, OpenCode, DeepSeek Harness, Cursor, Antigravity, Qwen Code, Kimi Code, etc.), pilotées sans être remplacées, avec un mode de configuration isolé ou la configuration globale déjà connectée. Les sessions vivent dans une base SQLite locale, avec recherche Ctrl+K, aperçus des fichiers produits (HTML, PDF, DOCX, PPTX, XLSX, CSV), traces d'outils et coût estimé par tour ; le mode groupe ajoute des salons multi-agents avec routage par @mention et compression automatique du contexte. S'y ajoutent un navigateur de fichiers local, Docker ou SSH, un terminal web, du vocal entrée/sortie, un Kanban, la gestion de compétences et une application mobile reliée par le réseau local ou un relais. Installation : installeur de bureau Windows, macOS ou Linux embarquant le moteur Hermes, ou deux commandes en web (npm install -g ekko-studio, puis ekko-studio-web start, avec Node 23 minimum, interface sur le port 8648) ; une image Docker existe. Les données restent dans ~/.hermes-web-ui et ~/.hermes. Licence : BSL-1.1, ce qui n'est pas une licence open source reconnue — usage personnel, éducation et recherche libres, mais vente, hébergement en mode SaaS ou intégration dans un produit commercial demandent une licence séparée ; le code passera en Apache 2.0 le 10 mai 2029. À garder en tête : c'est un atelier à configurer, pas un outil qui fonctionne en cinq minutes, et l'authentification se fait par jeton ou compte local, avec des identifiants de démarrage à changer dès la première connexion.

Terminal, fichiers, sauvegarde, auto-hébergement et réseau

STRATA FILES — un Finder survitaminé (github.com/cristipufu/strata-files). Gestionnaire de fichiers natif pour macOS, pensé comme alternative au Finder : recherche en langage naturel (« vidéos de plus de 500 Mo », « PDF du mois dernier »), avec filtres (ext:, size:>1gb, kind:movie, regex:) et interrogation des métadonnées Spotlight (camera:iphone, width:>1920, duration:>10m) ; une recherche peut être épinglée dans la barre latérale et rester à jour. Les tailles de dossiers s'affichent à l'ouverture, une vue carte montre l'occupation du disque, et des entrées repèrent les gros fichiers et les doublons. Il conserve les repères du Finder (raccourcis, glisser-déposer, Quick Look, onglets) et ajoute une palette Cmd+K, cinq vues, le double panneau avec copie, déplacement, comparaison et synchronisation, une file de copies que l'on peut mettre en pause, un historique des renommages, déplacements et suppressions qui survit au redémarrage. Pour le développement : statut Git et branche courante de chaque fichier, détection des projets Node, Rust, Swift, .NET, Python et Go, exécution de leurs scripts, mise à la corbeille des dossiers de construction comme node_modules. Connexions SFTP, S3 (Amazon, R2, B2, Wasabi, MinIO), conteneurs Docker, OrbStack, Colima, Podman ou Rancher, les clés S3 restant dans le trousseau macOS. Système : macOS. Prix et licence : gratuit, open source, MIT. Utile si votre poste est sous macOS : sur des millions de fichiers, l'index local fait la différence.

OPEN ANDROID DEX — transformer un téléphone Android en bureau complet (github.com/dotnetdreamer/open-android-dex). Application open source qui affiche les applications du téléphone dans de vraies fenêtres redimensionnables (barre des tâches, lanceur, accolement) sur l'écran d'un ordinateur, avec presse-papiers dans les deux sens, envoi de fichiers par glisser-déposer et installation d'APK, notifications et appels sur Windows et macOS. Le plus notable pour un usage technique : une Ubuntu 24.04 avec XFCE tourne dans un conteneur proot, sans root, avec Firefox, Chromium, VS Code et git proposés à l'installation (Node.js, GIMP et IntelliJ IDEA Community en option), et un moteur Docker qui accepte docker pull, docker run et docker compose — au prix d'une installation d'environ 3 Go et de performances de téléphone. Un bureau est même accessible dans un onglet de navigateur, par code à six chiffres et transport WebRTC, et l'accès distant à l'Ubuntu du téléphone utilise iroh (code de huit caractères, connexion chiffrée, ssh mon-telephone). Système : Android 8 ou plus récent côté téléphone ; application côté ordinateur pour Windows 10 et 11, macOS Intel ou Apple Silicon, et Linux 64 bits (sous macOS, l'application non notariée se débloque par une commande xattr). Licence : GPL-3.0, sans compte ni abonnement. Réserve honnête : le résultat dépend du téléphone, les fenêtres libres sur l'écran du mobile ne sont pas garanties, et les barres de titre personnalisées demandent l'application PC et Android 14.
