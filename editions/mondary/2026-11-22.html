Intelligence artificielle, agents et modèles locaux

HARK PRO — Assistant personnel cloud, disponible sur Mac. HARK PRO réunit recherche, achats et organisation dans un seul fil de discussion, avec un ordinateur cloud qui exécute les actions à votre place : navigation sur des sites, remplissage de formulaires, réservation. Disponible en application macOS (téléchargement direct depuis hark.com/mac), il conserve le contexte entre les conversations et peut programmer des tâches récurrentes. Le service n'est pas open source et repose entièrement sur les serveurs de Hark ; le modèle économique n'est pas précisé dans le billet. Une solution intéressante pour qui accepte de déléguer, mais à confronter à son besoin de contrôle.

Sciences, données et création graphique

CRAFT APPS — Sept applications créatives open source en Rust. L'équipe ArtCraft propose une suite de sept outils créatifs — édition photo, dessin vectoriel, montage vidéo, retouche RAW, édition PDF, motion design et mise en page — tous écrits en Rust, exécutés en local et gratuits. Chaque application peut être pilotée par des agents IA, ce qui ouvre des possibilités d'automatisation. Une alternative libre et performante aux suites propriétaires, qui tourne sans abonnement ni compte.

Terminal, fichiers, sauvegarde, auto-hébergement et réseau

SUNLIGHT — Toutes vos fenêtres Mac sur un canevas infini. SUNLIGHT rassemble les fenêtres ouvertes sur un canevas infini où l'on pince pour voir la journée entière et clique pour entrer dans une fenêtre à l'échelle 1:1. Gratuit, open source, en bêta. Peut remplacer le gestionnaire de fenêtres classique pour ceux qui préfèrent une vue d'ensemble continue.

Python et enseignement de l'informatique

NANOUI — Framework Zig pour applications de bureau et mobiles, binaires de 0,7 Mo. NANOUI est un framework Zig 0.17 qui permet de créer des applications avec une interface native dessinée par le GPU ou une interface web. Le binaire unique pèse environ 0,7 Mo et fonctionne sur cinq plateformes. Intéressant pour illustrer ce que permet un langage système moderne (Zig) dans la conception d'interfaces, et pour montrer aux élèves qu'une application complète peut tenir dans un fichier minuscule, sans Electron ni web runtime.
