Intelligence artificielle, agents et modèles locaux

RESULT — Agent IA personnel qui travaille sur votre iPhone plutôt que dans le cloud

Développé par Savio Martin (result.dev), RESULT est un agent IA conçu pour exécuter des tâches directement sur l'iPhone ou l'iPad de l'utilisateur. Concrètement, l'agent navigue sur les vrais sites web à travers le navigateur intégré de l'app, remplit des formulaires, compare des produits et réserve sans passer par une machine virtuelle distante. Vos cookies et sessions restent sur l'appareil ; les sites voient l'adresse IP de votre téléphone.

L'intelligence repose sur des modèles open-weight — Qwen, GLM et DeepSeek pour le texte, FLUX pour les images — transitant par la passerelle Vercel AI Gateway configurée en mode « zéro rétention ». Alternative locale : vous pairiez un Mac via QR code ou code à six chiffres pour faire tourner le modèle sur son matériel, avec téléchargement depuis Hugging Face. Le mode local sert aussi quand l'iPhone n'a pas de réseau. Si le Mac ne répond pas, le cloud prend le relais. Les champs sensibles (mots de passe, paiements) sont masqués avant de quitter l'appareil ; dès qu'une connexion, un paiement ou un CAPTCHA est demandé, l'agent rend la main. L'app s'intègre aux applications natives Apple (Calendrier, Rappels, Plans, Météo, Fichiers), accepte le partage depuis Safari, génère PDF, documents et tableurs, et poursuit ses tâches en arrière-plan même écran verrouillé. Gratuit sur l'App Store, iOS 18 minimum, avec un compagnon macOS pour le mode local. Lien : result.dev

GLASS — Espace de travail unifié pour conversations, pages et agents IA

GLASS réunit dans une seule application les échanges textuels, les documents, les projets et les agents IA, le tout accompagné d'un navigateur web complet intégré. L'application est annoncée sur cinq plateformes : macOS, Windows, Linux (AppImage et .deb), web, ainsi qu'iOS et Android en bêta publique. Version actuelle 1.0.39 (6 novembre 2026), l'éditeur assume le statut alpha.

Le navigateur n'est pas greffé : onglets et conversations partagent le même espace, un site peut se partager directement dans un chat, et le geste de vérifier une source pendant une discussion devient fluide. Les pages documentent ce qui reste attaché à sa conversation d'origine, rédigées à la main ou générées par un agent avec mention @ pour inviter quelqu'un. La fonction agents est centrale : on confie une tâche à un agent dans n'importe quel échange, il peut travailler sur les fichiers locaux ou sur un serveur distant. On peut utiliser ses propres abonnements (Codex, Claude). Les routines permettent de déléguer des tâches récurrentes, comme relever les e-mails chaque matin. Politique données explicite : aucune publicité, aucun entraînement sur les contenus utilisateurs, analytique désactivée par défaut. Libre et gratuit (statut alpha). Lien : glassapp.dev

Terminal, fichiers, sauvegarde, auto-hébergement et réseau

KATHAMO — Terminal GPU qui surveille vos agents de code

KATHAMO (GitHub) est un émulateur de terminal accéléré par GPU, écrit en Rust par Oval Labs. Il regroupe vos projets dans une barre latérale repliable, gère onglets et panneaux fractionnés, et surtout suit en temps réel l'état de vos agents de code — Claude Code, OpenCode, Codex, Pi, OMP, Command Code — en prévenant quand l'un est bloqué, en attente ou terminé. Contrairement à un terminal classique où le texte défile sans indiquer l'état réel, Kathamo résout le problème courant de trois agents tournant en fond sans que vous remarquiez qu'un d'eux attendait une autorisation depuis vingt minutes.

Chaque agent remonte son état par socket Unix ou séquences OSC 7501. Kathamo applique une hiérarchie stricte : bloqué, terminé, en cours, inactif. Une tâche terminée alors que l'onglet est masqué reste épinglée avec notification sonore et alerte visuelle. Les sous-agents s'affichent en retrait sous leur parent sans déclencher d'alerte doublonnée. Au redémarrage, tout revient : projets, disposition des splits, répertoire de travail, brouillons de saisie et historique. Le terminal lui-même inclut une barre de saisie proposant l'historique fusionné de zsh, bash et fish, complétion Git, recherche inversée, et un chat agent natif en Markdown avec cartes d'appels d'outils, commande /model et bascule Fast/Deep. Rendu GPU capable d'absorber des logs de compilation à 40 Mo/s. Licence : open source. Lien : github.com/olovalabs/kathamo
