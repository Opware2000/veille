Veille Clément Mondary — vendredi 27 novembre 2026

En bref — cinq billets publiés ce jour, tous traités. Un agent de code distribué (GOAT), un jeu d'extension pour agent (Omarchy), un outil CSS visuel (Flexbox Labs), un lanceur rapide (Heimdall) et une bibliothèque 3D de jeux (Boxshelf). Les trois premiers ont un intérêt direct pour l'enseignement ou la productivité.

Documents, notes et bureautique

FLEXBOX LABS — Outil visuel en ligne pour composer des layouts Flexbox et CSS Grid à la souris, avec export HTML/CSS automatique et sauvegardes locales, sans besoin de créer de compte. Intéressant pour la partie web de l'enseignement de l'informatique (niveaux seconde et première en SNT et enseignement scientifique) : les élèves peuvent expérimenter la disposition en flexion et en grille sans écrire le code, puis comparer avec la version exportée. Lire sur mondary.design

Intelligence artificielle, agents et modèles locaux

GOAT — Application open source sous licence MIT qui centralise la gestion des agents de code que vous utilisez déjà — Claude Code, Codex, Cursor, OpenCode — en les faisant tourner simultanément sur plusieurs machines. Vous pouvez les piloter depuis votre bureau, un navigateur web ou un téléphone. La possibilité d'exécuter plusieurs agents en parallèle sur différentes machines pourrait intéresser pour le développement personnel ou l'expérimentation pédagogique avec les outils d'agents de code. Lire sur mondary.design

BUILD OMARCHY PLUGINS — Suite de douze compétences (skills) dédiées à la fabrication d'un plugin Omarchy 4 Quattro, couvrant tout le cycle de développement : du choix de la surface au déploiement sur le marketplace, en passant par le scaffolding automatique, le langage QML, le débogage et les tests. Omarchy étant un client de messagerie open source extensible par plugins, cette resource est utile si vous envisagez de développer vos propres extensions ou d'étudier l'architecture de plugins. Lire sur mondary.design

Terminal, fichiers, sauvegarde, auto-hébergement et réseau

HEIMDALL — Lanceur d'application natif pour Windows de seulement 2 Mo : un simple Alt + Space et quelques lettres suffisent pour retrouver applications, fichiers et réglages système dans une liste classée. Pratique pour la navigation quotidienne entre les nombreux outils, mais réservé à Windows uniquement. Lire sur mondary.design

Sciences, données et création graphique

BOXSHELF — Interface 3D pour organiser et afficher sa collection de jeux Steam, Epic et émulateurs : jaquettes retournables, boîtiers ouverts, muséum et navigation à la manette. Le projet tourne sur Windows, Android et Linux, ce qui en fait un outil transversal plutôt qu'une application fermée. L'aspect « bibliothèque visualisée » en 3D est moins centré sur le jeu que sur la gestion et la présentation visuelle d'un catalogue. À retenir pour l'interface 3D, pas pour jouer.
