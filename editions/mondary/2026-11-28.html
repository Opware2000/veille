Terminal, fichiers, sauvegarde, auto-hébergement et réseau

MUXIN — Application de bureau native qui rassemble Macs, serveurs Linux, PC Windows et machines cloud dans une seule fenêtre. Chaque machine dispose de sessions de terminal persistantes (un petit agent installé garde les terminaux ouverts après fermeture de l'application), d'accès à distance au bureau en VNC jusqu'à 4K, de la visualisation des changements de code branchés sur pull request, et du pilotage de conteneurs Docker ainsi que de services systemd depuis le même espace. Un serveur MCP exposant plus de 90 outils permet aux agents IA (Claude Code, Codex, OpenCode, Gemini CLI, Amp…) d'emprunter vos machines comme espaces de travail. Les partions se font par lien pair à pair chiffré, sans ouvrir de ports sur le réseau. Gratuit et open source sur muxin.dev. Fonctionne sur macOS, Linux, Windows et iPad.

Documents, notes et bureautique

BOOKORBIT — Plateforme auto-hébergée transformant un serveur Docker en bibliothèque de lecture multi-utilisateurs. Prend en charge ebooks (EPUB, KEPUB, MOBI, AZW3, FB2), PDF, BD (CBZ, CBR, CB7) et livres audio (M4B, MP3, M4A, OPUS, OGG, FLAC), chacun avec son lecteur intégré directement dans le navigateur. La progression et les annotations sont synchronisées entre le web, une liseuse Kobo, KOReader et une application iPhone. Bibliothèques séparées par utilisateur, métadonnées enrichies automatiquement via une douzaine de fournisseurs, permissions fines et connexion OIDC/SSO (Authentik, Keycloak, Authelia). Tableau de bord avec statistiques de lecture et « Reading DNA ». Installation unique docker compose up -d avec PostgreSQL/pgvector, pas d'abonnement requis. Sur bookorbit.app.
