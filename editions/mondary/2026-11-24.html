Intelligence artificielle, agents et modèles locaux

Craft Anything est un moteur open source en Rust qui inspecte un site, une application ou un jeu pour en extraire la structure, puis charge un agent de code afin que celui-ci en reconstruise une version vérifiée contre l'original. L'outil fait travailler un agent de programmation sur la base d'une analyse statique du produit cible, ce qui permet de reproduire fidèlement une interface ou un comportement sans avoir à écrire le code soi-même. Licence non indiquée dans le billet, ouvertures possibles pour explorer le génie logiciel inversé ou construire des prototypes pédagogiques.
