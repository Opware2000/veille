En bref

Trois billets retenus sur les cinq publiés le 22 novembre : un bloc-notes natif écrit en Rust qui laisse ses fichiers en clair sur le disque (QUIET.MD), une boîte de réception unique pour piloter Claude Code et Codex (VESPIN), et un modem acoustique pour faire passer un petit fichier d'une machine à l'autre sans réseau ni câble (CHIRP).

Documents, notes et bureautique

QUIET.MD — Des notes locales qui répondent sans attendre. Application de prise de notes native écrite en Rust, sans Electron ni service inférieur : les textes restent dans un dossier de fichiers XML sur votre propre disque, et la frappe demeure sous 6 millisecondes même sur un document d'un million de caractères. Pour un usage enseignant, l'intérêt tient à l'absence de compte et d'abonnement : le dossier de notes se sauvegarde ou se synchronise par simple copie, et un fichier XML reste lisible sans l'application, ce qui réduit la dépendance à l'éditeur. Tourne sur macOS et Windows, en bêta gratuite ; la licence et le prix à venir ne sont pas précisés dans le billet, et le dépôt du projet n'y est pas cité, donc l'ouverture du code reste à vérifier.

Intelligence artificielle, agents et modèles locaux

VESPIN — Claude Code et Codex réunis dans une seule boîte de réception. Application macOS et web qui rassemble plusieurs agents de code au même endroit : on ouvre une tâche, on choisit un dépôt GitHub et on décrit le changement comme une issue ; l'agent travaille dans un bac à sable, écrit son plan, ouvre une pull request, et ne revient vers vous que lorsqu'il bute sur une décision, une relecture ou une tâche à valider. L'intérêt pour un professeur qui fait tourner des agents est de ne plus courir après trois fenêtres de conversation : une vue « Needs me » rassemble les fils qui attendent une réponse, et les fils se mettent de côté jusqu'à une heure donnée. Le projet se présente comme gratuit et open source sous licence Apache-2.0 ; il ne facture pas les modèles, qui tournent sur votre abonnement Claude ou ChatGPT, ou sur votre clé API Anthropic ou OpenAI. L'app Mac exige macOS 14 ou plus et une puce Apple silicon ; le web prend le relais sur téléphone ou sur une autre machine, avec le même espace de travail. Un serveur MCP et une intégration Slack permettent de le piloter depuis d'autres outils ; le dépôt reste jeune (créé en août 2026, version 0.27.0) et le cœur du flux passe par GitHub — dépôt, pull request, relecture.

Terminal, fichiers, sauvegarde, auto-hébergement et réseau

CHIRP — Transférer des données entre deux machines par le son. Modem acoustique qui tourne dans le navigateur : une machine joue une salve de tonalités, l'autre l'écoute au microphone et reconstruit le texte ou le fichier, sans réseau, sans câble, sans compte et sans serveur. Le mode rapide envoie quatre tonalités à la fois (1,5 à 7,9 kHz) à environ 320 bit/s — 100 octets en deux secondes et demie — quand le mode robuste descend à 85 bit/s pour résister au bruit ambiant, et un troisième mode se place entre 18 et 19 kHz. Un fichier est limité à 256 Ko et à quinze minutes d'antenne. Deux réserves que le projet ne cache pas : rien n'est chiffré, donc quiconque est à portée d'oreille peut écouter ou émettre, et la transmission reste à sens unique, sans accusé de réception. C'est plus une curiosité qu'un outil de production, mais pour dépanner entre deux postes isolés — un ordinateur et un téléphone posés sur la même table, une salle sans connexion — l'idée se retient. Le billet ne donne ni licence ni système au-delà du navigateur ; le dépôt GitHub (solst-ice/chirp) fournit un Dockerfile et un fichier compose pour héberger la page soi-même, ce qui permet de vérifier soi-même les conditions d'usage.
