Applications et outils nouveaux

Ladybird — navigateur web en version alpha

L'équipe SerenityOS a publié la première version alpha publique de Ladybird, un navigateur web dont le moteur de rendu est entièrement construit à partir de zéro plutôt que dérivé de Blink ou WebKit. Le code, écrit en Rust et C++, est sous licence BSD 2-Clause. Le dépôt compte près de 69 000 étoiles et reçoit des commits quotidiens. Des binaires macOS et Linux sont disponibles au téléchargement. La fonctionnalité phare est son indépendance : ni Chromium, ni Firefox ne servent de socle, ce qui en fait le seul grand navigateur à n'emprunter le chemin de personne. LadybirdBrowser/ladybird · GitHub

Harbor — serveur d'inférence IA locale avec clustering Thunderbolt 5

Le leaker Aaron Perris a mis au jour dans les fichiers d'Apple une nouvelle application appelée Harbor, actuellement en aperçu privé sous la marque Claris. Harbor transforme le Mac en serveur d'inférence IA privée : les modèles ouverts s'exécutent en local sur puce Apple Silicon, aucune donnée ne quitte le matériel. La fonctionnalité majeure est le clustering — deux Mac ou plus reliés en Thunderbolt 5 voient leur mémoire unifiée mutualisée en une seule ressource d'inférence, permettant de faire tourner des modèles dépassant la capacité d'une machine isolée ou de servir davantage de requêtes simultanées. Aucun ligne de commande n'est requise : détection automatique des appareils, téléchargement et chargement des modèles depuis l'interface graphique. Une publication publique semble prévue dans les semaines à venir. MacStories / 9to5Mac

Claude « Install as app » — artefacts Claude deviennent applications de bureau natives

Anthropic a introduit dans Claude for Mac et Windows une fonctionnalité baptisée « Install as app ». À partir de n'importe quel artefact créé avec Claude, on peut l'installer comme une application de bureau à part entière : elle obtient sa propre icône, s'ouvre dans sa propre fenêtre externe à l'interface Claude, peut envoyer des notifications, ajouter des entrées au menu bar, et bénéficie des connecteurs Claude. L'utilisateur choisit le niveau d'accès aux fonctions du système. Les applications ainsi créées peuvent être partagées. Fonctionnalité en bêta, uniquement disponible dans Claude for Mac et Windows. 9to5Mac

Inky — inférence Inkling 2 Mini sur Apple Silicon

Projet Rust (GPL-3.0, 8 étoiles GitHub, dernier commit 25 nov.) portant l'inférence du modèle Thinking Machines Inkling 2 Mini sur les puces Apple. Disponible aussi via Homebrew : brew install --cask ink. robotgamedevelopers/inky · GitHub

Grokmind — connexion Grok Bot aux vaults Obsidian

Le bot Grok se connecte désormais aux vaults Obsidian pour gérer notes et fichiers. Extension utile pour les flux de travail basés sur Obsidian combinés à l'IA. Product Hunt
