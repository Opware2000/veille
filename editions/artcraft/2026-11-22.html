Nouveautés et annonces

AutoCraft — un outil open source pour la maintenance de dépôts GitHub par IA. Brandon Thomas a présenté AutoCraft lors de sa conférence « Let's Open Source the World » au AI Engineer CODE Summit le 12 novembre. AutoCraft est décrit comme un « Model Harness » qui orchestre des modèles d'IA (Claude Haiku, Sonnet, Opus) pour trier les issues et pull requests, détecter les doublons, rédiger des correctifs et proposer des fusions. Les actions sont limitées par un tableau de bord où le mainteneur définit ce que l'outil peut faire automatiquement. Les builds s'exécutent dans un environnement Podman rootless et les appels de modèles dans un bac à sable Bubblewrap. Le code source est disponible sur GitHub (dépôt AutoCraft). Vu sur heise.de.
